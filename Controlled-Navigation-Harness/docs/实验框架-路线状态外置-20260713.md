# 实验框架：路线状态外置 v1.1（2026-07-13 整合版）

## 0. 一句话

小 VLM 的内部信念不可用（校准平线 ECE 0.46、三探针全灭、泛类地标绑错实例），但**显式维护的路线状态 + 几何证据是活的**（路线一致性初测 AUROC 0.748 vs 探针 0.54；角度/深度/里程计零校准可用）——把决策系统的证据源从"模型自报"换成"外置路线状态"，一个中枢喂三个决策面。

## 1. 核心架构：一个状态机，三个决策面

**路线状态机（程序化维护，非 VLM 内省）**：指令解析为有序子句序列（方向词 + 地标词）→ 逐步用 VLM 的**感知输出**（每视角地标匹配——它唯一可信的用途）推进匹配进度 → 维护：已完成子句、已见地标集、当前期待约束（方向 + 地标）、单调进度。

| 决策面 | 机制 | 证据源 | 对准的失败（干净基线账本） |
|---|---|---|---|
| **选路** | 约束驱动候选过滤/重排：期待"左转见 doorway"→ 左侧含 doorway 候选加权 | 路线状态 + 候选 angle_deg（几何） | 48% 随机游走（84% 有好候选选不中） |
| **终止** | 路线一致性门（覆盖×顺序×步数）∧ 类别匹配 ∧ depth veto；终段过桥记忆（carry_forward+深度） | 路线状态 + 深度 + 里程计 | 56 假停（泛类地标绑错实例）+ 5 擦边 |
| **恢复** | 未匹配约束驱动的主动观察（"期待 doorway 而候选无 → 转身找"）+ 位移停滞回溯 + 负目标黑名单 | 显式未匹配约束 + 里程计 | 23 耗尽 / 死胡同 / 38% 重复提停 |

**红线（不可协商）**：VLM 只作感知（"这个视角里有什么"），永不作信念（"我到了吗/我确定吗"）；一切以米为单位的推理期比较过血统检查；触发条件必须可计算（显式约束/几何），不用不确定性估计（已证不可测）。

## 3. 机制融合判定

**融合出新（纳入）**：

| 新机制 | 融合来源 | 状态 |
|---|---|---|
| **N1 负目标黑名单**：停止被拒→该位置记负证据，≥2 笔进冷却区（拒停+候选降权）。锚点的对偶——记"不在哪"比记"在哪"鲁棒（负判定来自程序化核验，可信；正判定来自 VLM 感知，不可信）。VLN-CE 无先例 | ConsistNav 非对称证据 × 路线核验 × HiMemVLN 局部记忆 | ✅ P0.4 过闸，进 Phase 1 终止轨 |
| N2 约束条件化感知预算：按当前期待约束分配 VLM 调用与分辨率 | AutoGaze × 路线状态 | 效率章 + 消融，Phase 2 后 |
| N3 状态转移门控慢-快调度：状态每步更新，完整推理仅在转移事件触发 | DualVLN/FSR-VLN × 状态机 | 实现节，系统贡献 |

**直接吸收（补引用）**：CA-Nav 约束分解（子句 schema）；Progress-Think 单调进度；MSNav 目标布局（并入终点子句约束）；HiMemVLN 回环软惩罚。

**只引用不做**：MSGNav VVD（下游站位互补）；AbstainEQA（弃权思潮）；Dual-Anchoring（related work 专段：同病两方——状态漂移/训练头 vs 信念脱钩/外置状态机）；SmartWay occupancy 航点（路线已关）；**REALM**——三重引用：① "80% 传统成功从未看见目标" = SR 通胀第二机制（第一机制 = 我们的 oracle 补贴），并列进评测卫生章；② 下游互补（其模块以"已停在目标 ±5m"为训练分布，我们修它的前提）；VSP = 我们停止门的训练式同构，收敛证据；③ 结论原文 "make reliable stopping decisions under partial observability... remain open" 可引作开场。

**竞态记录**：MSGNav（2511）→ ConsistNav（2605）→ REALM（2607），8 个月三篇填充"到达质量"空间，全部止步下游、全部把停止决策可靠性列为 future work——方向三重确认 + 倒计时。

**堆料纪律**：每个进正文的机制必须对应一个被测量过的失败类 + 一行消融。正文封顶 = 状态机 + 三决策面 + N1 + depth veto；N2/N3 进效率与实现节。
