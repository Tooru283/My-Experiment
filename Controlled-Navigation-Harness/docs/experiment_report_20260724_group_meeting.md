## 术语速查（先统一口径）

- **成功率（SR）**：最终停在目标 3m 内的比例。**路过率（OSR）**：轨迹上任一点曾进过目标 3m 的比例（"路过没停下"也算）。**转化率（OSR→SR）**：路过之后真能停对的比例。
- **悔值（regret）**：某个候选方向走过去后，离目标还剩多远（米）。越小 = 越少走冤枉路。
- **候选（candidate）**：这一步"能往哪走"的几个方向，每个有编号、角度、距离。
- **零样本（zero-shot）**：不在导航任务上做任何训练，直接拿现成大模型 prompt 着用。
- **区分力（AUROC）**：一个信号能不能把"选对"和"选错"分开。0.5 = 完全随机，1.0 = 完美。
- **模型内部向量（隐藏态）**：大模型在处理每个候选时，内部对它形成的一串数值表示。

## 0. 先看懂系统：决策管线的五个模块（输入 / 输出 / 作用）

导航每走一步，数据依次流过下面五个模块。本周所有实验都是在诊断"到底哪个模块是瓶颈"。

**① 候选方向生成器**
- 输入：当前位置的全景 RGB-D 图像
- 输出：一组候选方向（每个含 编号、相对角度、距离）
- 作用：把"连续空间能往哪走"离散成"几个具体方向"，供后面挑

**② 逐方向看图描述器**（唯一真正调用视觉模型的地方，每候选一次）
- 输入：每个候选方向对应的视角图像 + 指令
- 输出：该方向的文字描述（看到什么物体/场景）+ 一个"像不像目标、多远"的感觉
- 作用：给"选路器"提供每个方向的语义信息
- 📌 本周发现：它给的"远近感"和真实几何距离几乎无关（相关系数 0.175）——**是语言在猜，不是真在用视觉测距**

**③ 选路器**（纯文本大模型，注意：它不看图）
- 输入：指令 + 导航历史 + 各方向的文字描述（②的产出）
- 输出：`往编号 N 走`（或`停`）
- 作用：决定这一步往哪走
- 📌 本周发现：它选得**只比瞎猜强 9 个点、比"永远选最靠前那个"这种简单规则只强 1 个点**（见 §2）

**④ 进度自估器**
- 输入：指令 + 导航历史 + 当前观测
- 输出：一个"任务干完几成了"的数
- 作用：辅助判断是不是该停了
- 📌 本周发现：这个数和真实进度相关系数只有 0.12，还在 75 个点上把顺序估反了——**自己证伪自己，是负贡献**

**⑤ 停止判断器**
- 输入：持续的视觉确认信号（原来还偷看真值距离，已在上期审计中移除）
- 输出：停 / 不停
- 作用：决定什么时候宣布"到了"

> 一句话概括系统现状：**候选方向给得够（不缺方向）、信息也喂到了（不缺输入），但第③步选路器基本在随机挑。** 本周就是围着"③到底能不能救"打转。

## 1. 摘要（这周干了什么、得到什么）

上期留了两个"靠可观测信号的修复"（用深度否决停止、走不动就退一步）待验证。本周把它们跑到结论（**都基本无效**），然后顺着失败继续下钻，最后逼出一个决定性判断：**"改进选路器"这条路，在当前小模型 setup 下基本封死。** 四条主线：

1. **每步调用体检**——逐位拆开每一步到底在算什么，发现 **约 43% 的计算花在经不起检验的产出上**（④进度自估器自证伪、②看图描述器的距离感是语言在猜）。顺带纠正一个旧误解：**选路器是纯文本的，它不看图**；真正看图的是②逐方向看图描述器（每候选一次，所以每步真实的视觉模型调用有 5~6 次）。

2. **瓶颈定量到"选路器基本在随机挑"**——把"问题出在选路器"从感觉钉成数字：**只比随机强 ~9 点、比简单规则强 ~1 点**；"用深度判断该不该停"这个信号区分力 0.531（等于随机，死路）；"走不动退一步"几乎不改变轨迹（空转 1.9%）。附带做出一个**候选坐标还原法**（误差 0.000m），是后面所有离线分析的地基。

3. **候选先验打分（负结果）**——用人工规则给候选打分排序，**"选对候选"的命中率涨了 7 个点，但成功率只涨 1 个点（统计上等于没涨，p=1.000）**。原因：**"选得准"没能变成"走得到"**——因果链断在第二环。语义特征里只有"候选描述和指令下一步的匹配度"有用，人工规则能做到的天花板 57.5%。

4. **内部向量线性读取测试（本周决定性负结果）**——既然零样本这套到顶了，最后一个没验证的希望是：**大模型处理每个候选时的"内部向量"里，是不是藏着人工特征够不着的信息？** 我们把这些内部向量抽出来，训一个最简单的线性读取器去预测悔值。结果 **≈随机**（见 §6），且加大容量也捞不回来 → **"造候选打分头"这条路判死**。

**核心判断**：诚实的零样本基线是 SR 16% / OSR 21%，它上不去的原因，现在有**三条独立证据同时指向选路器**：选路器近随机（§2/§4）、人工先验补不动（§5）、内部向量里也没有可线性提取的信号（§6）。三条各自独立、结论一致，所以"在这个模型规模上改进选路环节"基本没戏。转入回退方案（换骨干快筛 / 把负结果写成论文）。

## 2. 核心数字一览

本周以离线分析为主，**没有新的整轮评测**，SR/OSR 沿用上期干净基线；本周产出主要是下面这些诊断结论：

| 结论 | 什么意思 | 数值 |
|---|---|---|
| 诚实零样本基线 | 推理不含真值、可复现 | SR 16% / OSR 21% / SPL 0.128 |
| 选路器 vs 随机 | 选对候选的命中率高多少 | 只 +~9 点 |
| 选路器 vs 简单规则 | 比"永远选最靠前"高多少 | 只 +~1 点 |
| 候选先验打分 → 命中率 | "选对候选"涨了 | +7 点 |
| 候选先验打分 → 成功率 | 但 SR 几乎没动 | +1 点，p=1.000（=没涨）|
| "用深度判断该不该停" | 这个信号有没有区分力 | AUROC 0.531（=随机）|
| 每步无效计算占比 | 花了算力但产出不可信 | 约 43% |
| 内部向量线性读悔值 | best 组合 | regret 1.16 / AUROC 0.52 → **FAIL** |

> 对比纪律：不同模型、不同口径之间不能直接比大小；只在同型之间比。

## 3. 每步调用体检：约 43% 的算力，产出经不起检验

**做了什么**：逐位拆开每一步的真实调用构成，看每个产出到底可不可信。

**逐模块结论（对照 §0）**：
- **④ 进度自估器**：输出的"完成度"和真实进度相关系数只有 0.12，还在 75 个点上把候选顺序估反 → 不只是弱，是负贡献。
- **② 逐方向看图描述器**：输出里的"距离感"和真实几何距离相关系数 0.175 → 基本是语言在猜，不是视觉测距。
- **合计约 43% 的每步计算**耗在这两类经不起检验的产出上，列为可砍项。
- 附带纠正：**选路器（③）是纯文本，它不看图**；看图的是②，每候选调一次，故每步真实视觉模型调用 5~6 次。底层的视觉编码器（SigLIP）每步都在参与（旧记录写"未启用"是错的）。

## 4. 瓶颈定量：选路器基本在随机挑

**做了什么**：在"走丢了的那些集"的决策点上，量选路器到底比随机好多少。

- **选路器命中率**：比随机只高 ~9 点、比"永远选最靠前的候选"这种简单规则只高 ~1 点 → 说明**换/重训选路器能捞回的空间极薄**。
- **"用深度判断该不该停"**：区分力 AUROC 0.531，等于随机，**死路**。
- **"走不动退一步"**：触发后几乎不改变轨迹，空转率 1.9%。
- → 上期预注册的两个可观测修复到此基本证伪，不再主攻。

**副产品 · 候选坐标还原（后续所有分析的地基）**
- 输入：追踪里的 位置、朝向、候选相对角
- 输出：每个候选的世界坐标 (x, y)
- 作用：不用重跑仿真，就能在离线把"候选"和"目标"几何对齐，从而算悔值
- 精度：推导出 θ = −朝向 − 相对角，重建误差 **0.000m**

## 5. 候选先验打分：命中率涨了，成功率没涨（断在第二环）

**这个模块**
- 输入：每个候选的语义/几何特征（含"候选描述和指令下一步的匹配度"）
- 输出：给候选打分并重排，让选择更偏向"靠近目标"的候选
- 作用：试图从"选得更准"这一环把成功率顶上去

**结果**：

| 环节 | 指标 | 结果 |
|---|---|---|
| 第一环：选得准 | 选对候选的命中率 | **+7 点** ✅ |
| 第二环：走得到 | 成功率 SR（配对检验）| **+1 点，p=1.000** ❌（等于没涨）|

**读数**：
1. **因果链断在第二环**——"选对候选"没能兑现成"最终走到并停对"。和终止侧的老毛病同源。
2. 逐个语义特征里，**只有"和指令下一步的匹配度"有用**，其它接近噪声。
3. 即便做到完美打分，**天花板也只有 57.5%**——人工先验路线的上限已经探到。

**这直接定义了下一步的必要性**：人工特征/先验（= "用数据集常识打分"的最强形态）已经试到顶。要突破，只能换更强的输入——大模型学出来的"内部向量"。§6 就是去测这个。

## 6. 内部向量线性读取测试：最后一个希望，结果 ≈ 随机（候选打分头判死）

**动机**：§4、§5 证明零样本选路器近随机、人工先验也补不动。唯一没验证的上升空间是——**冻结的大模型内部，对每个候选算出的"内部向量"里，是不是藏着人工特征够不着的悔值信息？** 如果有，就值得训一个"候选打分头"去用它；如果没有，整条训练线可以关掉。这是一次性、便宜的去/不去闸门。

下面把这一步用到的每个模块列清楚（输入 / 输出 / 作用）：

**① 内部向量抽取**
- 输入：已经记录在追踪里的选路器完整 prompt + 候选编号（100 集全有）
- 输出：每个候选那段在大模型第 16/20/24/28/32 层的内部向量（两种汇总方式：取平均 / 取末位）→ 存成 `hidden_states.npy`；外加每点一个"离线重跑的决策和线上是否一致"的标签
- 作用：**不改线上、不重跑评测**，就拿到大模型对每个候选的内部表示
- 为什么能离线：prompt 已存、线上就是贪心解码可复现、后端就是同一个大模型服务（同权重同精度）

**② 离线复现一致性检查**（确认离线抽的向量代表线上那次决策）
- 输入：离线重跑得到的决策 vs 线上记录的决策
- 输出：一致率 + 三段裁决（≥95% 通过 / 85–95% 灰区留一致子集 / <85% 重来）
- 作用：如果离线和线上对不上，抽出来的向量就不算数——这一步先卡住
- 结果：全集 **639/683 = 93.6%（灰区）**；对不上的点几乎都是"停还是走"的边界犹豫，属预期

**③ 内部向量线性读取测试**（正式的去/不去测量）
- 输入：候选的内部向量（当特征）+ 候选的悔值（当答案，来自 §4 的坐标还原 + 目标位置）
- 输出：按场景 5 折交叉验证的 悔值 / 区分力 / 命中率，以及是否过闸门
- 作用：测"内部向量能不能**用一个线性函数**读出哪个候选悔值最小"
- 预注册闸门：交叉验证 悔值 ≤ 0.85 m/步 **且** 区分力 > 0.60

**结果（两个口径一致 FAIL）**：

| 口径 | best 组合 | 交叉验证悔值 | 区分力 | 命中率 | 裁决 |
|---|---|---:|---:|---:|---|
| 一致子集（预注册主口径，n=612）| 第20层/取平均 | 1.161 | 0.521 | 28.1% | **FAIL** |
| 全量（敏感性，n=656）| 第20层/取平均 | 1.168 | 0.532 | 27.7% | **FAIL** |
| 参照：让大模型自己选 | — | 0.995 | — | 36.6% | — |

**怎么读这三个数（互相印证 = "内部向量线性读 ≈ 随机"）**：
- **命中率 25–28%**：每个决策点约 4 个候选，纯随机挑就是 25% → 读取器基本就是在随机挑；
- **区分力 0.52**：随机是 0.50 → 几乎零区分力；
- **悔值 1.16**（全部 20 个 层×汇总方式 组合都在 1.16–1.28）：**比大模型自己选的 0.995 还差**。

三个指标从三个角度指向同一结论，不是某个环节的 bug。**悔值差 = −0.17 m/步 ≈ −1.1 m/集**——闸门地板要 +0.12、上线要 +0.5，实测是负的，连基线都没够着。

**结论**：**冻结大模型的候选内部向量里，没有可以用线性方式读出来的悔值排序信息** → **候选打分头这条训练线判死**。

**稳健性检查（加大容量，回应"是不是读取器太弱/汇总时丢了信号"）**：把线性读取用的成分数从 64 加大到 128 / 256 / 512（8× 容量），best 区分力分别 0.521 / 0.512 / 0.474 / 0.537——**始终在 0.47–0.54 徘徊（≈随机，256 甚至低于 0.5）**，悔值稳在 ~1.16（始终劣于基线 0.995）。**加容量捞不回信号 → FAIL 不是"读取器太弱"造成的，信号确实不在。** 这也基本堵死了"零训练相似度打分（候选向量 vs 指令下一步的向量）"这条支路——它只是读取器搜索空间里的一个固定方向，而 512 维已覆盖远超单个语义方向所需的信息，仍为随机。

**顺带澄清一个方法学问题（零样本）**：候选打分头一旦用悔值标签训练，就**不再是零样本**（冻结骨干救不了这个说法），得改称"冻结骨干 + 轻量监督适配器"，而且不能在评测集上训、再报评测集。本次的交叉验证只用于"诊断信号在不在"，不是上线成绩口径。（不过既然已 FAIL，这条不用再纠结。）

## 8. 方法论沉淀（比单个数字更值钱）

1. **便宜测试挡贵决策，又一次生效**：内部向量线性读取用一天、纯 CPU、决定性地否掉了整条候选打分头训练线的盲目投入。一致性检查（分钟级）挡在全量抽取前、全量抽取挡在训模型前、小样本试跑挡全量。
2. **中间指标涨 ≠ 目标指标涨**：候选先验命中率 +7 但 SR +1（p=1.000）第三次印证"第二环转化"才是真瓶颈——任何新方法都要直接报终点指标 + 配对检验，别看中间指标自嗨。
3. **组件性质要亲自核**："选路器看图"这类旧误解被逐位体检推翻（其实是纯文本、不看图）；候选坐标能离线精确还原（误差 0.000m）也是靠追到最原始的 位置/朝向。
4. **同后端同权重才敢离线复现**：内部向量能走离线重跑，前提是查明线上就是同一个大模型服务；一致性检查就是这条假设的实测闸门。
