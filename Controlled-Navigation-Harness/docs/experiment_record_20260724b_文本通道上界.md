# 文本通道信息量上界：选路瓶颈定位到感知→文本接口

> 纯离线、零 GPU、~1 小时。脚本 `paper_analysis/scoring_head/text_channel_ceiling.py`（可复跑）。
> 数据：clean_baseline_v1（20260719 跑）**721 个决策点**（有描述且候选≥2）。

## 0. 为什么做这个

打分头 FAIL（隐藏态线性无 regret 信号、加 8× 容量仍随机）之后，剩两种解释：
**(a) 9B 表示能力不够**（→ 换骨干）；**(b) 输入端就没有这个信息**（→ 换感知接口）。
两者的处置完全相反，必须先分开。关键线索：**选路器是纯文本调用，全程不看图**——
它读的是 SpatialBot 生成的场景描述，而那些描述的距离读数已被证明是语言先验
（整数占比 64%、与真实距离 r=0.175）。故先测**文本通道里到底有多少"哪个候选通往目标"的信息**。

## 1. 三个检验与结果

| # | 检验 | 结果 |
|---|---|---|
| 1 | 描述**可区分性**（候选间物体集 Jaccard） | 均值 **0.356**；最优vs最差 **0.306**；描述完全相同的步仅 0.1% |
| 2 | **指令-描述词汇重合** | 最优候选 2.05 词 vs 最差 1.87 词；"最优>最差"占 **38.4%**（平局 32.6% → 无信息基线 33.7%） |
| 3 | **纯文本 BoW listwise 探针**（有监督，场景级 GroupKFold-5） | **34.2% ± 5.5%** |
| — | 9B 零样本选择器（同折同口径） | **33.2%** |
| — | 随机基线 | 25.7% |

## 2. 结论：瓶颈在感知→文本接口，不在模型

**决定性的一条：一个有监督训练的词袋探针（34.2%），只与 9B 零样本（33.2%）打平。**

- 最简单的**有监督**文本模型 = 最强的**零样本**大模型 → **9B 已把文本里的信息榨干**，
  它不是"没读懂"，是**文本里就这么多**。
- 文本通道相对随机只值 **~9 个点**，而 9B 拿到了全部 9 个点。
- 检验 1 排除了平凡解释（不是"所有描述都一样"——描述确实各不相同，Jaccard 0.36）；
  检验 2 说明差异**与目标方向无关**（最优/最差候选的指令词重合几乎相同，38.4% vs 无信息基线 33.7%）。
  → **描述在讲"房间里有什么"，不携带"哪个方向通往目标"。**

**这一次性解释了打分头 G1 的失败**：隐藏态里读不出 regret 信息，不是 9B 表示差，
而是**输入端就没有可编码的信息**。两个负结果合成一个正面结论。

**完整因果链现在闭合**：
```
图像 →（SpatialBot 转文本描述）→ 方向信息在此丢失 → 9B 榨干残余 ~9 点 → 选路近随机 → SR 20
                  ↑ 真凶
```

## 3. 对性能路线的直接含义

| 方向 | 判断 |
|---|---|
| 换骨干（更大/不同 LLM） | **救不了**——再大的模型也只能榨同一份文本；除非同时换感知接口 |
| 训打分头（任何输入形态基于当前文本） | **已死**（G1 FAIL + 本检验解释了原因） |
| **让选路器直接看图（多模态 selector）** | **唯一有物理希望的改动**，且从未被测过；绕开文本中介 |

## 4. 下一个闸门（预注册，写在跑之前）

**M1：多模态选路上界检验**（离线，先不动 harness）
- 样本：大 regret 步（regret>1m）中随机抽 **60 个决策点**，每点取其 N 个候选方向的 RGB 图。
- 任务：把「指令 + 当前已走步数 + N 张候选视角图」交给一个 VLM，问"哪个方向最可能通往终点"。
- 对照（同一批 60 点）：9B 文本选路的实际选择、几何启发式（最长步）、随机。
- **闸门：图像选路命中率 ≥50%**（要明显超过结构化组合的 44.2%、文本上界的 ~34%）。
  - 过 → 信息确在图里、文本丢了它 → 值得改 selector 为多模态（工程投入才有依据）。
  - 不过（≈40% 或更低）→ **信息在图里也拿不到** → 本 setup（小 VLM + 航点选择）性能空间关闭，
    转最小可发表版 / 换任务。
- 成本：60 点 × ~4 图 ≈ 240 次 VLM 调用，**~1 小时，可用现成 9B 多模态或云 API**。
- ⚠ 前置：**图像未存进 trace**（trace 只有文本）。需一次小规模重跑（ep20 级，或直接在
  60 个目标决策点上重放）把候选视角图 dump 出来——这是本检验唯一的工程成本。

## 5. 论文价值（顺带）

本检验是一条独立、干净、可复跑的负结果，**建议进诊断章**：
> 「在文本中介式 VLN 架构中，感知→文本接口构成信息瓶颈：
> 有监督文本探针（34.2%）≈ 零样本 9B（33.2%），二者仅比随机（25.7%）高约 9 点。」

它与已有的 C4「选路环三方证据」互补：三方证据说"选路不行、先验不转化、表示无信号"，
本条给出**为什么**——并把矛头从模型转向架构（文本中介）。
