## 6. 纪律（历次教训沉淀）

- **预注册闸门**：先写死判定标准再跑。
- **配对检验**：ep100 一切对比用逐集 McNemar；点估计差 2–4pp 不作声明。
- **血统检查**：任何新触发/门控信号，wiring 前查数据源（oracle 泄漏即由此抓出）。
- **单开关 A/B**：一次只开一个机制，归因高于速度。
- **贵决策挡在便宜测试后面**：smoke 挡全量、离线挡在线。
- **目录名会撒谎**：模型身份以 trace `metadata.llm` 为准；⚠ **同一目录下可能有多轮跑**，glob 前先去重（20260802 因此把 n 报大一倍）。
- **★ oracle/上界类指标取了 min/max，对照必须取同样的 min/max**（20260802 新增：否则测的是密度不是信号，注册检验即因此误判）。
- **★ 标题不锁结论**：结论会被推翻，标题不会跟着改，而标题是最容易被引用的部分（20260802 新增）。
