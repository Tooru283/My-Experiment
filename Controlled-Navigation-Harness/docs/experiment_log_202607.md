**C. 为什么阈值 3.0m 却停在 4.04m —— veto 读的不是到目标距离**
`_depth_stop_ok` 取的是**正前方中心区深度中位数**。任何 3m 内的墙面/家具都满足条件，与目标位置无关。所以它只能表达"别在空旷处远远地停"，无法表达"该在这儿停"。

**D. 误杀风险（预注册红线：真到达误杀 = 0）**
16 集成功里约 6–8 集的停止目标是**开口类**——`371 门口/楼梯顶`、`513 餐厅入口旁`、`259 走廊`、`531 楼梯平台`、`526 敞开的白门`、`824 刚进屋`、`586 刚进屋`。站在开口处中心深度天然 >3m，veto 会系统性误杀这一类真到达。
⚠ 基线跑时 veto 关闭、`_depth_stop_ok` 直接 return **未记任何深度读数**，故此风险目前只有文本启发式证据，实测值要等本轮跑完。

**E. 本轮净预期：OSR +5~10 / SR −3~+3 / SPL 下跌。**
两个开关（veto + 回溯）**全部作用于"能不能走到"，无一作用于"停得准不准"**。上行来自 56 集假停的大池子，下行来自 16 集成功的误杀，量级接近故方向不定。→ **本轮按测量跑，不按性能跑**；产出 = 锚点所需的三个输入（新 OSR 量级 / 新 OSR 转化率 / 停止时刻深度分布，用于标定锚点 ≤2m 阈值）。

## 一quater、2026-07-20b 中介检验：Arm C 之谜已解，选择层规则重写

覆盖步内同状态对比（n=307，decision_audit 逐步对账）：override 仅改善目标欧氏距离
**−0.094m/步**（改善 154/恶化 147）≈ **0.35m/集**；臂级 regret 0.988→0.965、
测地增益 −0.015（被轨迹发散淹没）。
**结论：p=1.000 的原因不是"选得准没用"，是"这个先验没让轨迹变准多少"——
命中率指标夸大干预强度（分歧步候选几乎并列）。**
→ 新规两条（即日生效）：
1. 选择层一切目标/验收改用**米制 regret**（现状 LLM 0.99m/步，打分头目标 ≤0.6）；
2. **上线闸门：离线米制期望效应 <0.5m/集的选择层干预不上线**。

**20260720c/d 补充（假说①证伪 + regret 结构）**：欧氏 vs 测地 r=0.869、翻转率 ~4%
→ 标签没问题；regret **高度集中**——39% 的步（regret>1m）贡献 89% 的总 regret，
这些步最优转角中位 90°（路口），几何启发式恰在此失效（最优=最长步仅 38%）。
**打分头的靶收窄为：路口步的方向判别。**

**20260720e 分岔已裁决——training-free 方向先验关闭，表示级为唯一活路**：
方向词可用 80%，但最优候选与活跃词一致率仅 31.9%（随机 26.9%）；oracle 圈定大错步
可赚 +1.30m/集，**可部署全步形态净负**（全替换 −0.91 / 违规否决 −0.74 m/集，闸门 +0.5）。
根因 = 激活问题（何时用哪条线索），代理子句对齐噪声太大。
→ 打分头任务书：**读指令+视觉表示，联合学"步-子句对齐"与"候选-线索符合"**；
训练目标与验收 = 米制 regret；上线闸门 0.5m/集 不变。
（副产品：左右转符号约定 sign=−1 已标定，成功集 65% vs 35%。）

## 一septem、2026-07-27 M1 可行性裁决 + "换 pipeline"的决策规则

### AG. 距离通道消融（20260730b，纯离线，n=721，脚本 `paper_analysis/scoring_head/distance_channel_ablation.py`）

**编造距离的性质**：与真实航点距离 **r=+0.171**（n=2266）；8797 个报出值中**整数占 86%**；
报出中位 1.00m vs 真实航点中位 1.50m。

**当启发式用（命中最优候选）**：

| 依据 | 命中 |
|---|---|
| **真实航点步长最长** | **35.2%** |
| 报出最近物体"最近" | 25.9% |
| 报出最近物体"最远" | 23.7% |
| 随机 | 25.7% |

→ **同一个物理量，真值值 +9.5 点，编造值 0 点。而 prompt 里放的是编造的那个。**

**BoW listwise 探针（场景级 GroupKFold-5，与 §一sex 同配方）+ 米制 regret**：

| 臂 | 命中 | 米制 regret | Δ/集 |
|---|---|---|---|
| 9B 现状（部署中） | 33.4% | 0.995m | — |
| 文本（删掉距离句） | 35.6% | 0.999m | −0.03m |

| 只用真实航点距离 | 35.8% | 1.184m | −1.25m |
| **只用编造距离** | **22.8%（低于随机）** | — | — |

**三条结论：**
1. **编造距离是本项目量化过的唯一「负资产」输入**：单独用低于随机；混进文本把命中 35.6→34.5、

   最刺眼：**只用真实距离命中 35.8% 高于 9B，米制却差 1.25 m/集**——选对时准，选错时错得远。
3. **对 §一sex 的精确化（非推翻）**：那个"文本通道只值 9 点"是在**距离被编造的前提下**测的。

### AH-4. 🔴 终点锚点注册检验的结论已撤回：0.90m 是密度效应，不是语义匹配

> 脚本 `paper_analysis/terminal_anchor/registration_test.py`（含 `subgroup()`）。

20260730 我从"OSR 成功组 oracle 中位 **0.90m** / **82.4%** 落在 3m 内"读出
"注册机制成立、信息确实进了池子"。**该读法错在对照不对等** ——
oracle 取的是「匹配实体中的最近者」，就该与「**随机抽同样数量实体的最近者**」比，而不是「随机抽一个」。

补齐对等对照（OSR 成功且锚点有匹配，**n=17**）：

| | 中位 | <3m 占比 |
|---|---|---|
| 语义匹配 oracle | 0.90m | **82.4%** |
| **随机抽同数量实体取最近（对等）** | 1.75m | **82.4%** |

**关键指标完全打平。** 池子中位有 **104 个实体**、匹配的仅 4 个 ——
随便抽 4 个取最近，一样 82.4% 落在 3m 内。逐集语义仅在 **11/17** 集更优（符号检验不显著）。

→ **正确表述：在 n=17 与对等对照下，语义匹配相对随机抽取无可检出优势。**
"注册机制本身成立"这句撤回；ACN 的 S2/实体状态方向**未获支持，也未被否定**（n 太小）。
⚠ **通用教训**：凡是 oracle/上界类指标取了 min/max，对照必须取**同样的 min/max**，否则测的是密度不是信号。

### AI. SkillNav：把跨步记忆写进打分层，而不是写进 prompt

核心主张：现代 VLM 导航器已维护一个 **curiosity value map**（打分面）；
把它当作**可写基底**承载跨步行为记忆，**零 token 成本**，避免 prompt 单调膨胀与注意力稀释。
在打分与执行之间插一层 **Refinement Layer**，三档权限**固定合成序**：

`Hard Override ∘ Lower-Bound Boost ∘ Soft Scaling`

四条对我们有直接价值：

1. ~~**★ 它解释了 Arm C 为什么弱**~~ —— 🔴 **20260802b 已实测，不成立，降级为"未检出"。**
   原假设：Arm C 是纯 hard override 用在日常分歧步，改成 soft scaling（按比例重加权）会更好。
   **实测**（656 决策点，场景级 GroupKFold-5，打分头分数标准化后加 `β·1[LLM 所选]`，β 从 0 扫到 ∞）：

   | β | 0（=Arm C 式硬替换） | 0.25 | 0.5 | 1.0 | 1.5 | 2.0 | 3.0 | ∞（=全听 LLM） |
   |---|---|---|---|---|---|---|---|---|
   | 米制 regret | 0.940 | 0.917 | 0.943 | 0.932 | **0.891** | 0.913 | 0.954 | 0.957 |

   **曲线非单调、无结构，全程在 0.89–0.96 之间跳，最好点与折间噪声同量级。**
   → **"软混合优于硬替换"在可部署形态下测不出来。**
   ⚠ 限定：我们没有 LLM 的逐候选分数（只有 argmax），故此"软混合"是弱版本；
   但**这正是能部署的版本**，所以负结果是决策相关的。SkillNav 的三档设计**在其 value-map 基底上可能成立，
   在我们的候选列表基底上没有证据。**
2. **★ 其 Lower-Bound Boost 就是我们 07-06 定稿、从未实现的「目标锚点」（队列 4）**，
   连门槛都一样（连续 2 帧确认 → 深度反投影成 3D 锚点）。**但用法相反**：
   我们打算用在**停止判据**（"距锚点 ≤2m 才准停"），他们用在**评分**（保证朝锚点方向不掉分、别跟丢）。
   → **这是"深度当裁判 vs 当尺子"（§一undecim AG）模式的第二次出现。** 同一机制，当门判死、当偏置有效。
3. **其 anti-stuck + ABAB 振荡检测 = 我们 `visual_graph_memory` 的 `loop_flag`/`revisit_score`**，
   锁在 `MEMORY_DIAGNOSTIC.LOG_ONLY=True`。而 20260730 实测 **69/100 集发生过重访**（非相邻步 ≤1m）。
4. **消融解耦有说服力**（HM3D v0.2，Qwen2.5-VL-7B）：prompt 通道降误报 FP 10.1→8.9；
   打分层降超时 MS 20.4→18.7。**语义记忆治语义混淆，空间记忆治空间低效，互相替代不了。**

⚠ **迁移障碍**：其基底是 value map（ObjectNav 的 frontier 打分面），我们只有候选列表。
soft scaling / hard override 可直接落到候选分数；lower-bound boost 需"区域"概念，
但原文实为 *"any direction whose ray passes through the anchor region retains a high score"*，对候选列表可做。
