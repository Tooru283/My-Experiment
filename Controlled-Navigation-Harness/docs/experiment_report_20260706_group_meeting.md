## 1. 摘要

本周经历了一个完整的"冲顶 → 证伪 → 审计 → 重置"周期，是项目开始以来信息量最大的一周。四条主线：

1. **性能冲顶**：e3_carry_forward 把 4B SR 推到 **24%**（历史最高，OSR→SR 转化 92.3% 全场最高）；切换 9B 并调参（token 上限 + E5 rescue 距离守卫）后 9B 达 SR 24% / OSR 28% / SPL 0.200，假停 52→20。
2. **触发式再观测路线被预注册实验证伪**：为 P1（校准驱动的选路再观测）设计的离线校准闸门 FAIL——自一致离散度 AUROC 0.542（≈随机），言语化自报退化（几乎从不承认困惑），且天花板分析显示即便完美触发器也被步数预算卡死。**省下了 ~30h 注定无效的在线实验。**
3. **Oracle 审计（本周最重发现）**：例行信号血统检查发现模拟器测地目标距离 `latest_goal_dist` 泄漏进终止栈推理路径——7 个消费者、5 个在决策时分支。移除后干净重跑：**SR 24→16、OSR 28→21（配对 McNemar p=0.022，显著）**。8 个 SR 点是 ground truth 买来的。
4. **论文重定位与地基完工**：叙事从"可靠终止机制"重置为"**小 VLM 信念校准分析 + 评测卫生 + 可观测修复**"。分析章与审计章全文完稿，全部数字 trace 复核，图表管道脚本化，其余章节段落级框架立起。

**当前核心结论**：诚实的零样本基线是 SR 16% / OSR 21%。小 VLM 的失败不是缺信息（P0 注入无增益 p=0.21）、不是缺候选（84% 决策点有靠近目标的选项），而是**选择层随机游走 + 终止信念与现实脱钩（ECE 0.46）且三类不确定性探针全部失效**。修复方向已锁定为两个纯可观测机制（深度 veto、位移回溯），代码已就绪待 A/B。

## 3. 性能线：e3_carry_forward 与 9B 调参

- **e3_carry_forward（4B SR 24%）**：PSG carry_forward + E3 abstain/override 组合，转化率 92.3% 封顶——"一旦接近目标几乎总能成功"，SR 天花板 = OSR，攻击方向从终止转向 OSR。
- **9B 调参**：`NAVIGATOR_MAX_TOKENS` 1024→2048 修复长输出截断（空预测 fallback 22.6%→0），9B 从全面弱于 4B（20/23）反超至 24/28。
- **E5 rescue 距离守卫**：假停 52→20——但审计（§6）证明该守卫读的是 GT 距离，此压制大半是买来的（干净版假停回升至 56）。

## 4. 诊断线：瓶颈在哪一层（全部 trace 可复算）

**4.1 选路 = 选择层问题，非覆盖问题**（Run1，72 迷路集 640 决策点）：
- 所选候选 48.0% 走远 / 48.1% 走近，净进展 +0.071m/步 ≈ **随机游走**；
- ~84% 决策点存在能靠近目标的候选（口径待与诊断脚本统一），真死胡同仅 11–16%；
- → 换/重训航点预测器攻击的是没坏的部分，waypoint 路线正式关闭。

**4.2 信息注入无增益（P0 证伪）**：把 WaypointBert 真实几何注入 selector prompt，点估计变差（24→18）但配对不显著（McNemar 16 失配、11伤/5帮、p=0.210）。结论收紧为"**naive 信息注入无增益**"——瓶颈不是信息量。

**4.3 终止信念与现实脱钩（E1，9B 干净 trace 878 决策点）**：
- **ECE = 0.463**；所有置信桶经验到达率 6–13%——置信度对"到没到"零信息量（最大桶 N=336、置信 0.94、到达 11%）；
- 分距离可见性：成功半径内仅 46% 报可见（欠检测），5–8m 处 **51%** 幻觉可见、8m+ 处 33%（4B 为 22%/17%，9B 幻觉翻倍）——这就是 56 个假停平均在 8.3m 的机制；
- 跨 backbone 一致（4B ECE 0.324 同形状）。

## 5. 触发式再观测路线：预注册证伪（P1 关闭）

设计：迷路时触发多采样/换视角再选路，触发信号 = 校准后的诱导信念。执行了预注册闸门（AUROC ≥0.60 且 bootstrap 下界 >0.55）：

| 探针 | AUROC | 95% CI | 裁决 |
|---|---|---|---|
| 自一致离散度（K=5，方向聚类熵） | 0.542 | [0.502, 0.582] | FAIL |
| — 非覆写干净子集（n=526） | 0.530 | [0.482, 0.576] | FAIL（洗掉标签污染反而更差） |
| 言语化 confusion（Fast-SmartWay 忠实复刻） | 退化 | confuse=true ≤5%，置信堆 4–5 | FAIL |
| choice logprob | 待跑 | — | — |

三个关键读数：
1. **最低离散桶（5/5 全票一致）仍有 36–44% 错误率**——模型不只是错，是全票一致地错；错误是"自信的错误"。
2. **天花板**：选路错误占全步 43% 且在信号空间近乎均匀——oracle 完美触发器也要 30% 预算才拦 70% 错误；dispersion 仅比随机触发好 +3~4pp。
3. **设计教训（进论文方法节）**：re-observe ≠ re-sample。同分布重采样探测不到自信错误；恢复机制必须获取**新证据**（换传感器/行为一致性），不能重新查询同一个后验。

闸门的价值：12h 离线否掉方向，省 ~30h 在线跑。Fast-SmartWay 的 +4.5 自省杠杆在我们 setup（文本 grounding 小模型）不迁移。

## 6. Oracle 审计与诚实重置（本周最重）

**发现**：单一变量 `latest_goal_dist`（模拟器测地目标距离，与 SR 同源 GT）进入终止栈推理路径：

| 门 | Oracle 判据 | 真实触发 | 性质 |
|---|---|---|---|
| E5 远距停止阻断 | d>4.0 | 168 次 / 39 集 | **决定性** |
| E3 到达 override / 弃权带 / 轨迹旁路 | d<3.0 / 3.0 / 3.5 | 14+24+34 次 | 决策路径 |
| PSG 主动停止/提交 | d<2.0 | 86 次 / 22 集 | 决策路径 |
| rescue 增益门 | Δd | 594 次 | 0 决定性，仍移除 |
| ArrivalGate | d≤4.0 | 仅日志 | 免动 |

**修复**：统一替换规则——oracle 距离合取项 → **持续视觉确认（≥2 连续步）**；增益门关闭。commit `clean_baseline_v1`。

**干净重跑与配对归因**（p=0.022）：−8 = **6 集早期自信假停**（第 3–5 步停在 4.4–6.8m，原被 GT 阻断器否决——GT 在替 agent 购买额外探索，连 OSR 都被抬高）**+ 3 集近距擦边**（3.2–3.5m，原被 GT 近距门捞回，= 近距欠检测的直接代价）**− 1 集意外翻正**。

**定性**：没有一处是有意作弊，全是"合理工程守卫"逐渐把 GT 兑换成 SR。审计方法（单变量污点追踪）便宜且可复用——这一发现升格为论文贡献之一。
