# P1 设计方案：校准驱动的选择性再观测（选择层）

> **一句话**：在**高代价路由决策点**上，当选择器处于不确定带时，不贪心提交最高分候选，而是**选择性地多采样再推理 / 再观测**，用已有的 `thought_fusion + test_decisions` 机制仲裁。training-free、零训练、复用休眠基础设施。这是论文分水岭（C2）与攻 OSR 的主杠杆。

---

## 1. 动机与数据依据（为什么是这个而非换 waypoint / P0）

- **覆盖率诊断（[[current_task]] §7.1，2026-07-02）**：72 迷路集 640 决策点，前向候选 ~84% 步都存在、真死胡同仅 11–16%；**失败集是随机游走——所选候选 48% 走远目标、净测地增益中位 +0.03m**。→ 瓶颈是**选择/路由**，不是候选生成。waypoint 路线关闭。
- **E1 校准（[[e1_calibration_20260702/README]]）**：小 VLM 信念失准（近距欠检测 43%、Termination ECE 0.32、9B 更差）。路由决策**根本没有显式信念**（`selector_final` 只有文本，无 scalar confidence）——所以 P1 在路由侧的任务是**诱导出不确定性信号**，而非重校准。
- **P0 佐证（Run2 前34集净负）**：往脆弱的选择层塞更多信息（真实距离）反而伤 SR/OSR。→ 治本不是"喂更多信息"，而是"**不确定时慢下来再决策**"。

**结论**：把终止侧已验证的"弃权+再观测"原语（E3）扩展到路由决策。

| 组件 | 位置 | 现状 | P1 如何用 |
|---|---|---|---|

## 3. 机制设计

### 3.1 两层选择性自一致（core）

```
每步:
  sample_1 = move_to_next_vp(...)           # Tier-0: 永远先跑 1 次 (成本不变)
  if not TRIGGER(step_context):             # 不确定带外
      commit(sample_1)                       # 贪心提交, 与现状同, 零额外成本
  else:                                      # 不确定带内 (VoI: 值得花算力)
      samples = [sample_1] + [move_to_next_vp(...) for _ in range(K-1)]  # 再采样
      [可选] observation = re_perceive(...)  # P1b: 再观测(扩视角/重感知)
      fused = thought_fusion(samples)        # 唤醒休眠机制
      choice = test_decisions(fused)         # 分歧仲裁
      commit(choice)
```

- **选择性**是精髓：只在不确定时付 K 倍推理成本（VoI——把算力花在最可能出错的决策点）。绝大多数步维持 1 次，速率退化可控。
- **分歧度**（fused 后的候选数 / 投票熵）是**诱导出的、可校准的**不确定性信号——区别于 Fast-SmartWay"问 MLLM 你困惑吗"（未校准内省）。

### 3.2 触发信号 TRIGGER（**本方案唯一需拍板的设计决策**）

路由侧无显式信念，触发必须用**决策前可得**的代理。三个候选：

| 代理 | 来源 | 优点 | 缺点/风险 |
|---|---|---|---|
| **A. 进度停滞**（近 k 步测地增益 ≤ ε，或连续负增益）| `recent_distance_gains` | 直击"随机游走 48% 走远"；强信号 | **依赖 oracle 距离**（harness 既有设定，arrival_gate/E3 都用，但论文需声明）|
| **B. 相位=recover** | 已算 phase | 零成本、已是迷路判定 | 触发较晚（已经迷路才触发）|
| **C. 视觉新颖度停滞 / 原地打转** | 观测重复度、位移小 | **非 oracle**、纯 training-free | 需新指标，噪声待测 |

**推荐首版 = A ∪ B（并集触发），并行记录 C 作对照**：
- A+B 直击已量化的失败（随机游走 + recover），能最快验证 P1 是否有效（分水岭判定）。
- oracle 依赖：harness 本就用 oracle 距离做 arrival_gate/PSG/E3，P1 沿用同一设定，论文明确声明并做"用非 oracle 代理 C 的降级实验"回应审稿。
- 若 A+B 有效但审稿担心 oracle → 用 C 复现，证明机制不依赖 oracle。

### 3.3 再观测动作（两个强度，先弱后强）

- **P1a 再推理（re-reason）**：只多采样 K 次 + 融合仲裁，不动观测。最省、复用休眠机制、直击选择噪声（随机游走）。**首版做这个。**
- **P1b 再感知（re-perceive）**：触发时扩展观测（更多方向视角 / 重跑感知），再采样。攻 E1 的近距欠检测（目标没看见）+ 16% 覆盖失败。**P1a 见效后叠加。**

- **统一命题**：终止（E3/E5，已验证锚点）+ 路由（P1）都是"高代价决策点上基于失准信念的过度提交"，用**同一个** training-free 校准驱动选择性再观测机制修复。

## 9. Path B：耐用校准流水线（取代 §8 的脆弱重建；这是主力）

> **动机**：把触发建立在"校准后的诱导信念(vote-dispersion)"上，而非启发式。核心洞察（用户 2026-07-02）：**推理时用 oracle=泄漏；离线校准时用 oracle 结果当监督标签=合法**。部署的触发器只看 dispersion。但绝不用"从 trace 反向重建 prompt"（与 prompt 模板/observation 格式/history 日志紧耦合，改代码即失效）——而是**记录真实 prompt + 共享采样函数**，做到零重建、活过重构。

### 9.0 理论靠山与 novelty 边界
- vote-dispersion ≈ self-consistency confidence（Wang et al.）/ semantic entropy（Kuhn; Farquhar et al., Nature 2024）搬到具身决策。**引用义务**：相关工作须引这条线。**novelty 精确表述**：*首次将校准后的诱导信念用作具身导航的再观测触发*——不是发明 dispersion。
- **对我们有利**：semantic entropy 在自由文本上要按语义聚类；我们的 dispersion 在**离散候选集**上是精确投票熵、无需聚类，比 NLP 原版更干净。
- **对 confusion-prompt 的话术**：行为化信念 vs 内省自报——模型说不说自己困惑不可靠，它的行为分歧不会撒谎。
- **关键认知**：校准不是写一次永久用的产物。**模型/prompt/温度/流程一变，dispersion→错误率关系就变，校准带必须重算**。故设计成**可重复运行的流水线**，不是冻结脚本。

### 9.1 共享采样器（`spatialNavigator.py`，一份代码供在线 P1 + 离线校准共用）

```python
# 新增：从固定 prompt 采 k 次，返回预测候选 id 列表。在线/离线唯一真源。
def sample_predictions(self, system_prompt, user_prompt, candidate_ids,
                       k=1, temperature=0.0, max_tokens=None):
    preds = []
    for _ in range(max(1, k)):
        out = self.llm.gpt_infer(system_prompt, user_prompt,
                                 max_tokens=max_tokens, temperature=temperature)
        self._last_logger and self._last_logger.info(out)
        if "Prediction:" in out:
            pv = self._parse_prediction(out.split("Prediction:")[1], candidate_ids)
            if pv is not None:
                preds.append(pv)
    return preds

@staticmethod
def vote_dispersion(preds):
    # 归一化投票熵∈[0,1]. 0=全票一致, 1=k次全不同. denom=log(k).
    import math
    from collections import Counter
    if not preds: return None
    n = len(preds); c = Counter(preds)
    H = -sum((v/n) * math.log(v/n) for v in c.values())
    return H / math.log(n) if n > 1 else 0.0
```
`move_to_next_vp` 重构为**先拼一次 user_prompt、可选返回它**，内部改用 `sample_predictions`（`k=1,temperature=0` → 与现状**逐字节等价**，向后兼容）：

```python
    user_prompt = NAVIGATOR['user'].format(
        ", ".join(candidate_ids + [STOP_CANDIDATE]), current_step, instruction,
        actions, landmarks, history_traj, estimation, observation)
    preds = self.sample_predictions(NAVIGATOR['system'], user_prompt, candidate_ids,
                                    k=k, temperature=temperature, max_tokens=max_tokens)
    thoughts = []  # 若需 thought，sample_predictions 同步返回 pred_thought（见实现）
    if return_prompt:
        return preds, thoughts, True, user_prompt
    return preds, thoughts, True
```
（前提：`gpt_infer` 增加 `temperature` 形参，默认 0 → 现有行为不变。同 §8 Diff 0。）

### 9.3 离线校准流水线（脚本 `scratchpad/p1_dispersion_calib.py`，消费日志，已就绪）
1. **收集**：加完 9.1/9.2 后跑收集，`P1_REOBSERVE.ENABLED=False`，只多记 `navigator_prompt`+保持 `waypoint_candidates`/`geometry_query` 开（供聚类角度/坐标，见 §9.3a）。**建议 4B 全 100 集**（~6-7h）：天然含全部 **72 迷路集（富集，判闸门）**+ 28 到达集（代表分布，拟合部署带）——一跑两用，免子集选择。这是唯一的"新 rollout"。
2. **保真自检**：`sample_predictions(k=1,temperature=0)` 重发 logged prompt，应**复现** `selector_final.selected_candidate`。prompt 原样记录 + temp0 贪心确定性 → **复现率应≈100%**；低于此说明日志/schema 有问题，先修再校准。
3. **采样 + 簇 dispersion**（§9.3b）：每点 `sample_predictions(k=K, temperature=TEMP)`。
4. **标签**：原贪心是否走错 = `distance_gain_selected < 0`（测地，已记）。**标签噪声**：合法绕行/探索也会为负 → AUROC 别期望 0.9；必要时用数据集 `reference_path` 换成"偏离参考路径"降噪。
5. **预注册闸门（跑之前定死，防事后目测）**：
   - 主判 **AUROC(dispersion→走错) ≥ 0.60 且 bootstrap 95% 下界 > 0.55** → PASS（建校准触发）；**≤0.55** → FAIL（触发方案推倒重来，省一轮 online）；之间 = GRAY（dispersion 单独太弱，上聚类/re-perceive）。
   - 辅判 Spearman ρ≥0.3, p<0.05；reliability 每桶带 **Wilson 95%CI**。
   - **闸门定性**：离线 AUROC 只是**便宜的 kill-switch**，不是创新点成立的证明——真正证明靠 §9.4 预算配平消融（校准臂支配 confusion-prompt/随机）。

5b. **保真闸门 + 跨后端一致性（预注册 20260703，护栏1-3）**：收集跑在 `transformers serve`（贪心，忽略温度）上做，但 K 采样必须换 **vllm**（唯一能采样的后端）。保真自检因此**兼作跨后端等价测**：
   - **匹配定义 = 解析后决策层**（所选航点相同），**非字节层**——vllm/transformers 数值核不同，temp=0 输出文本可微异属正常，按字节判会假 FAIL。
   - **三段裁决（跑前定死）**：`≥95%` PASS（两后端贪心等价 → 现有 prompt+标签有效，**免 12h 重跑**，直接烧 K）；`<85%` RERUN（后端漂移过大 → 须在 vllm 重跑收集拿干净 baseline+prompt）；`85–95%` GRAY（**剔除失配点**后用剩余点过闸门——失配点标签跨后端无效）。
   - **GRAY 判读偏差**：失配点多为**近平局高不确定点**，剔除使校准集偏"易" → **AUROC 可能被低估**，真值应 ≥ 报告值。
   - **采样参数入校准条件**：temp/**top_p（vllm 默认1.0 但显式钉死）**/per-request seed 列表/**后端=vllm 0.21** 全写进 `.meta.json`。原则"校准随 {模型/prompt/温度} 重算"**扩为 {模型/prompt/温度/后端}**。
   - **12h vllm 基线重跑的时机（护栏4）**：即使保真 95% 过，per-step 5% 失配在 ~8 步/集上复利 → episode 级轨迹会漂 → 决胜对比（P1 vs baseline）严格要 vllm 基线。但 12h **只在闸门 PASS、确定要打在线实验时才花**；闸门 FAIL 则不打在线、重跑白烧。**顺序：保真 → 烧 K → 闸门 →（PASS 才）vllm 基线重跑与 P1 在线并排。**

### 9.3a 采集需一并保留的事件（点 5）
`navigator_prompt`（新增）+ `waypoint_candidates`（候选 `angle_deg`，供方向聚类）+ `geometry_query`（`world_point`，供空间聚类/富标签）+ `selector_final`（贪心）+ `post_action_progress`（`distance_gain` 标签）。后四者默认已记，采集 run 只要别关，且与 `navigator_prompt` 同 step 对齐。

### 9.3b dispersion 指标：跨步可比 + 方向聚类（点 4，semantic-entropy 精髓）
- 候选每步基本一方向一个，原始熵不跨步可比 → **相邻候选按角度阈值合并（`CLUSTER_MERGE_DEG=45°`）成方向簇，再算熵**；两个近邻航点票分裂 ≠ 真不确定。
- 主指标 = **归一化簇熵**（除 log K，跨步可比）；稳健对照 = **1−top簇占比**。
- 不做聚类 → 拥挤候选场景 dispersion 系统性偏高，单调性可能被噪声埋掉。血统 = semantic entropy（先聚类再算熵）。

### 9.3c 温度是校准条件的一部分（点 3）
采样 `TEMP` 直接改变 dispersion 分布 = 校准的隐藏超参。**写死（0.7）**，并加**一致性硬约束：离线校准的 TEMP 必须 == 在线 P1 部署 TEMP**，否则部署时分布与标定不符、带失效。§9.0 "须重算"清单 = {模型, prompt, **温度**, 流程}。

### 9.4 决胜消融 —— 预算决策（写死，防日程崩）
横轴 = **额外 navigator 调用数(compute)**（非触发次数，K 可变时二者不等）。四条臂：①校准 dispersion 带 ②confusion-prompt（Fast-SmartWay 代理：问模型"你困惑吗"）③progress-stall（§8 A∪B 启发式，降级臂）④预算匹配随机（下界，关键）。

**关键洞察：四臂 risk-coverage 曲线全部可离线算，零 GPU。** 四个都只是不同的"何时弃权"信号，信号值在收集数据上都能离线提取：dispersion（replay 已算）/ confusion-prompt（对 logged prompt 补问一句）/ A∪B（`recent_distance_gains`+`phase` trace 已有）/ 随机（平凡）。扫弃权阈值即得曲线（coverage=未再观测比例，risk=已提交决策走错率）。**这证明"哪个信号最会识别坏决策"（selective-prediction 质量）。**

**预算配平决策**：
- **离线**：四臂完整 risk-coverage（零 GPU）→ 定出支配信号 + 选一个配平工作点。
- **在线**（唯一离线证不了的：识别坏决策后再观测是否真提升端到端 SR，因在线会改轨迹）：**仅在该工作点验证** —— baseline（=§9.3 的 4B+E5 收集跑本身） + 校准-P1 + confusion-prompt-P1 = **额外 2 跑**（可选第 2 工作点 +1）。总在线 ~3-4 跑，稳排进 7/27。**否决** 4臂×3预算点=12跑（排不下）。
- **诚实边界**：离线 risk-coverage=触发器识别质量；在线=再观测确实治得了。互补，别把离线曲线当 SR 证据。审稿若坚持逐臂在线 → 用"离线全比 + 在线验证赢家"这个 selective-prediction 标准结构挡。

校准臂应在**离线整条曲线上支配**其余三条 + **在线工作点** SR 增益 > confusion-prompt —— 赢下这个，第 1 创新点才成立，比 SR 多涨两点更值钱。

### 9.5 re-observe ≠ re-sample（写进方法节，第二个对 Fast-SmartWay 的区分点）
K 次采样是**探测器**（诱导+校准 dispersion），不是解药：**同分布重采样降不了认知不确定性**。故两层响应：
- 投票集中 → 直接提交（K 次没白花，thought_fusion 边缘化降**推理噪声/aleatoric**）；
- 投票分散 → **re-perceive（新视角/新证据）**才是治**认知不确定**的旗舰响应。teleport setup 下的"新证据"= 看全景里没 surface 的方向（12 选 ~4）/ 用不同 prompt 重跑 SpatialBot 感知（正好攻 E1 近距欠检测），均无需先提交移动。
