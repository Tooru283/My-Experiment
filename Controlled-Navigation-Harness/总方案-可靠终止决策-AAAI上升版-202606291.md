# 总方案：面向零样本 VLN-CE 的小模型终止决策失准与可靠提交机制

> 今日日期：2026-06-29

本文档是在 2026-06-26 版“到达感知异构 pipeline”方案上的 AAAI 上升版。核心调整是：不再把“到达模式 / 异构 pipeline”作为主要创新点，而是将其降级为实验载体；论文主问题上升为“小规模 VLM 在具身任务中如何可靠地提交以 STOP 为主实例的高代价决策”。其中 `STOP` 仍然是主实验对象，但论文概念不应被压缩成单一动作，而应扩展为一组更广义的 commitment decisions。

新的研究主张是：在零样本 VLN-CE 中，小模型并非完全无法抵达目标邻域，而是经常在已经接近目标后，因终止决策失准而无法将 Oracle Success Rate（OSR）转化为 Success Rate（SR）。STOP 是具身导航中最清晰、可度量、代价最高的不可逆决策之一，但它只是 commitment decisions 的一个特例；因此近目标终止应被视为研究“小模型可靠提交机制”的任务载体，而不是论文贡献的上限。

## 1. 研究定位

### 1.1 从工程模块到科学问题

原始问题容易被表述为“给小模型增加一个终点监测模块”。这一说法过于局部，评审容易将其理解为 stop verifier 或工程 pipeline。

AAAI 版本应改写为：

```text
在零样本具身导航中，小规模 VLM 何时应该提交 STOP、指代确认、分支选择和终止视点这类高代价决策？
当模型置信度失准时，如何通过弃权与主动再观测，降低错误提交带来的轨迹风险？
```

对应的论文主线为：

1. 发现并量化 OSR→SR 转化缺口，说明“到达目标邻域”和“可靠提交终止”是两个不同能力。
2. 证明小规模 VLM 在以 STOP 为主实例的提交型决策上存在系统性校准失效。
3. 提出可弃权、可主动再观测的可靠终止机制，将强制二元判断改为更一般的可靠提交过程。
4. 通过跨 backbone、跨方法和可选跨任务证据，证明该机制不是单一模型或单一轨迹设置下的偶然技巧。

### 1.2 一句话版本

> We study reliable stopping for zero-shot embodied agents with small VLMs, showing that the main bottleneck is not only reaching the goal neighborhood, but reliably committing to high-cost decisions such as STOP under miscalibrated confidence.

中文版本：

> 本文研究零样本具身智能体的小模型可靠终止问题，指出其关键瓶颈并非单纯能否抵达目标邻域，而是在置信度失准条件下能否可靠提交 STOP 及其他高代价提交决策。

## 2. 当前证据基础

在本地 4B 配置下，最优一次 ep100 评测的 Oracle Success Rate（OSR）为 27–29%，而 Success Rate（SR）仅为 18–19%。这意味着每百个 episode 中约有十个曾进入目标 3 米范围，最终却未能停留在成功区间内。

| 指标 | 4B 最佳 ep100 | 含义 |
|---|---:|---|
| OSR | 27–29 | 进入目标 3m 内的能力 |
| SR | 18–19 | 最终停留于 3m 内的能力 |
| 转化率 (SR/OSR) | ~65% | 进入邻域后成功终止的比例 |

该观察支持一个更强的问题定义：当前小模型的剩余瓶颈不只是“导航能力不足”，还包括“终止提交能力不足”。如果这部分 episode 能被可靠转化，4B 模型的 SR 理论上可接近 27–29%，显著高于当前 Open-Nav-GPT4 的 19% 报告值，并优于不足 10B 规模的若干变体。

外部方法也存在类似转化缺口。例如 P2DNav 的 4B 结果可达到 SR 35，但其 OSR 约为 51，转化率约为 69%。该方法的巡航能力强于本工作，但 OSR→SR 的损失仍然明显，说明终止提交不是 Open-Nav 独有问题，而是零样本导航系统中可能普遍存在的瓶颈。

当前假设：

- 已知事实：本地 4B 配置存在 OSR 与 SR 的稳定缺口。
- 推理结论：该缺口至少部分来自近目标终止失败。
- 仍需验证：缺口中 T1–T5 各类失败的真实占比，以及置信度失准是否能被 ECE / risk-coverage 等指标稳定刻画。

## 3. 相关工作边界

现有零样本 VLN-CE 方法，包括 Open-Nav、HiMemVLN、P2DNav、CA-Nav 等，通常将 STOP 作为统一决策流程中的一个候选输出，而不是作为需要独立可靠性建模的不可逆提交动作。P2DNav 将 STOP 并入方向选择阶段，R3 和 MSGNav 引入终止前验证或视点决策，但这些机制仍偏向任务局部验证，而不是围绕小模型置信度失准建立可靠提交框架。

需要谨慎处理已有工作：

- 不能主张首次提出 last-mile 问题。MSGNav、SLING、AnyImageNav 等已经在 ObjectNav 或 image-goal navigation 中讨论过 last-mile / last-meter。
- 不能主张首次提出阶段切换架构。SLING 与 SAGE-Nav 已包含探索阶段与近目标阶段的切换思想。
- 可以主张在零样本 VLN-CE 中，首次将 OSR→SR 转化缺口作为中心可测目标，并将其与小 VLM 的终止决策失准联系起来。
- 可以主张提出面向小模型置信度不可靠性的可弃权终止机制，而非直接沿用强模型 verifier 或学习式门控。
- 可以主张通过跨 backbone 与跨方法分析，证明终止提交缺口具有一定普遍性。

与 SAGE-Nav 的关键区别应写清楚：SAGE-Nav 的 GAFN 是训练得到的连续门控，可靠性来自监督或强化学习信号；本文处于零样本小模型设定，对齐分数本身可能失准，因此中等置信度区间尤其危险。本文不是在不可信分数上做连续混合，而是在证据不足时选择弃权并主动取证。

## 4. 方法概念

### 4.1 从 STOP 到 commitment decisions

现有系统通常将 STOP 视为一步二元动作：停或不停。本文将其改写为更一般的可靠提交过程。这里的关键不是把动作空间无限扩张，而是识别具身导航中一组高代价、低频、但一旦提交就会强烈影响轨迹的 commitment decisions：

| 提交类型 | 含义 | 是否主实验 |
|---|---|---|
| `COMMIT_STOP` | 提交终止，结束 episode | 是 |
| `COMMIT_REFERENT` | 确认当前指代对象 / 区域就是任务目标 | 否，分析与辅助实验 |
| `COMMIT_BRANCH` | 进入某个拓扑分支或房间路径 | 否，分析与辅助实验 |
| `COMMIT_VIEWPOINT` | 选择当前 / 候选视点作为终止停靠点 | 否，分析与辅助实验 |
| `ABSTAIN / REOBSERVE` | 证据不足时延迟提交并补充观测 | 是，机制核心 |

本文不主张把这四类都做成完整动作头，而是将它们作为一个统一的 commitment 视角来组织分析；主方法仍聚焦 `COMMIT_STOP`，其余三类用于解释为什么 `STOP` 单点不足以概括终止决策空间。

### 4.2 可靠提交过程

```text
近目标证据出现
  → 进入终止候选状态
  → 主动再观测
  → 判断目标满足性与空间关系
  → 输出三态决策：提交 COMMIT / 继续导航 / 弃权并再观测
```

核心变化在于：模型不被迫在证据不足时给出二元判断。对于小模型而言，最危险的并非完全没有信号，而是有中等强度但不可靠的信号。弃权机制允许系统把“我不确定”转化为一次低成本取证动作，从而降低误停与漏停。

### 4.3 到达感知双模式作为实验载体

系统仍可保留原方案中的双模式结构：

```text
每一决策步:
  到达邻域? ──否──> 巡航模式: Open-Nav 文本观测 + waypoint 选择
            ──是──> 到达模式: 主动再观测 → 终止满足性验证
                              → 提交 COMMIT / 继续 / 弃权再观测
```

但论文写作中要降低“异构 pipeline”的贡献权重。它的作用是提供一个清晰、可归因的实验组织方式：

- 巡航模式对应原始导航能力。
- 到达模式对应终止提交能力。
- 二者的差异使 OSR→SR 转化率可以被单独分析。

### 4.4 切换器设计

切换器决定何时进入终止候选状态。它可以综合以下信号：

- 距离估计偏近或最近距离已进入目标邻域。
- 当前视角出现目标或到达线索。
- 语言指令已进入 approach / verify 阶段。
- 行为轨迹出现近目标徘徊、回退或 recover 信号。

切换器自身是新引入的失败点，因此必须先以 log-only 方式评估 precision / recall。设计倾向是适度提高召回率，让到达模式内部的弃权和验证机制兜底，而不是用过严硬触发错过真实近目标场景。

## 5. 终止与提交失败分类

T1–T5 仍然是本文的重要资产，但应从“pipeline 子问题”改写为“终止与提交失败类型”。其中 T2/T4 更接近 referent 与 viewpoint commitment 的失败，T5 更接近 branch-level commit 失败。

| 编号 | 失败类型 | 表现 | 可测信号 | 处理方式 |
|---|---|---|---|---|
| T1 | 到达识别失败（漏停） | 进入 3m 后未识别、继续前进 | OSR=1, SR=0；min_dist 小、final_dist 大 | 当前视角出现到达证据即触发终止候选 |
| T2 | 指代提交失败（误停 / 错认） | 在干扰物或错误实体上提前提交 | STOP 时 dist>3m，邻域存在相似物 | 验证 referent 是否满足指令，不满足则拒绝提交 |
| T3 | 弱终点漏停 | room/doorway 等区域目标下阈值过严 | OSR=1/SR=0 集中于弱终点词 | 按目标类型调整证据要求，允许连续证据提交 |
| T4 | 终止视点不满足 | 几何到达但视角不可见或关系不成立 | dist<3m 但 target_visible=false | 在近目标候选中选择更满足指令的停靠视点 |
| T5 | 分支提交漂移 | 抵达后进入 recover 或错误拓扑分支 | 近目标后 recover，距离回升 | 抑制大幅移动，仅允许不损害最近距离收益的候选 |

这张表在论文中的作用不是罗列工程规则，而是建立错误分析框架：每一类失败对应一种可观测信号、一种风险类型和一种可靠提交修复策略。主文只需要把 `COMMIT_STOP` 讲透，`COMMIT_REFERENT / COMMIT_BRANCH / COMMIT_VIEWPOINT` 用来说明 STOP 背后其实是一组高代价提交决策，而不是唯一动作。

## 6. AAAI 版实验设计

### 6.1 主指标

AAAI 版本不能只报 SR / SPL。必须增加能支撑“失准与可靠提交”的指标：

| 指标 | 作用 |
|---|---|
| SR | 最终任务成功率，作为主任务结果 |
| OSR | 是否曾到达目标邻域，表示巡航能力上限 |
| OSR→SR Conversion Rate | 核心指标，衡量到达后是否可靠提交 |
| SPL | 约束指标，防止主动再观测带来过大路径代价 |
| False Stop Rate | 衡量误停风险 |
| Missed Stop Rate | 衡量漏停风险 |
| Termination ECE | 衡量 STOP 置信度校准误差 |
| Brier Score | 衡量终止概率预测质量 |
| Risk-Coverage Curve | 衡量允许弃权时风险如何随覆盖率变化 |
| T1–T5 Breakdown | 支撑错误分析与机制归因 |

### 6.2 必做实验

M0：补齐原始 A0 基准  
运行 4B 裸跑 Open-Nav，记录 SR、OSR、SPL、nDTW、min_dist、final_dist、STOP 时间点、轨迹阶段和可用置信度。该步骤是所有归因的前提。

M1：转化缺口分析  
统计 OSR=1, SR=0 的 episode，计算转化率，按目标类型、距离、轨迹阶段和失败模式分组。目标是证明终止失败不是少量偶发样本，而是可复现的系统性缺口。

M2：终止校准分析  
对 STOP / NOT-STOP 决策构建校准曲线，计算 Termination ECE、Brier Score 和 false stop / missed stop。目标是证明小 VLM 的终止置信度不能被直接当作可靠提交信号。

M2b：提交空间分析  
对 `COMMIT_STOP` 之外的 `COMMIT_REFERENT`、`COMMIT_BRANCH`、`COMMIT_VIEWPOINT` 做轻量 trace 统计或案例分析，展示高代价提交错误如何沿轨迹传播。目标不是立即把它们都做成完整模块，而是证明“STOP 不是孤立动作，而是提交空间中的一个关键节点”。

M3：arrival gate log-only  
只记录切换器命中，不改变行为，计算触发 precision / recall。目标是证明切换器不会制造过多无关干预。

M4：最小可靠提交机制  
加入 T1 自动终止候选与三态决策，观察 OSR→SR 转化率是否提升，同时监控 false stop 与 SPL。

M5：完整到达模式  
加入 T2/T4 满足性与视点验证、T3 弱终点处理、T5 抗漂移机制和主动再观测。逐项消融每个模块对应的失败类型下降幅度。

M6：跨 backbone 验证  
在 4B、7B、8B 上分别评测 A0 与完整版，绘制模型规模与转化收益曲线。可选扩展到 72B，用于说明大模型是否自然缓解终止失准。

M7：跨方法转化缺口分析  
收集或复现实验中可获得的 Open-Nav、HiMemVLN、P2DNav、CA-Nav 等方法的 OSR、SR 与转化率，证明“高 OSR 未必高 SR”，终止提交是独立于巡航能力的瓶颈。

### 6.3 可选增强实验

若时间允许，可补一个轻量跨任务证据，使论文从 VLN-CE 局部问题上升为更一般的不可逆决策问题。

优先级建议：

1. ObjectNav stopping：最自然，和 STOP 决策同构，但可能需要额外环境与数据适配。
2. EQA abstention：与弃权机制理论更近，若能利用 AbstainEQA 现成设定，成本可能更低。
3. 只做跨指令类型泛化：成本最低，可将 room、object、region、doorway 等终点类型作为“弱跨任务”证据。

如果时间紧，主线先确保 L2 完整：VLN-CE 内的问题刻画、校准分析、可靠提交机制、跨 backbone 结果必须成立。跨任务可以作为加分项，不应拖垮主实验。

## 7. 消融结构

建议采用以下命名，保证读者能看懂每一步增加了什么：

| 名称 | 设置 | 目的 |
|---|---|---|
| A0 | 原始 Open-Nav 4B | 原始行为锚点 |
| A1 | A0 + harness logging | 验证日志外壳不改变行为 |
| G0 | arrival gate log-only | 评估切换器质量 |
| R1 | T1 终止候选 | 验证漏停修复 |
| R2 | R1 + T2/T4 验证 | 验证 referent / viewpoint 提交失败修复 |
| R3 | R2 + T3/T5 处理 | 验证弱终点与分支漂移修复 |
| R4 | R3 + abstention + active re-observation | 完整可靠提交机制 |

R 系列中的 R 表示 Reliable Commit，而不是 R3 方法，论文中需避免命名冲突。正式写作时可换成 `Base / Gate / Verify / Abstain / Full`。

## 8. 预期论文贡献

AAAI 版本的贡献建议写成：

1. We identify and formalize the OSR-to-SR conversion gap in zero-shot VLN-CE, showing that reliable stopping is an independent bottleneck beyond reaching the goal neighborhood.
2. We provide a termination-centric calibration analysis for small VLM agents, revealing systematic miscalibration in high-cost commitment decisions with STOP as the primary observable case.
3. We propose an abstention-aware reliable stopping mechanism that actively gathers additional evidence before committing to STOP and other high-cost commitment decisions.
4. We validate the mechanism through failure decomposition, calibration metrics, and cross-backbone analysis, showing consistent improvements in OSR-to-SR conversion under constrained path cost.

中文对应：

1. 本文识别并形式化零样本 VLN-CE 中的 OSR→SR 转化缺口，说明可靠终止是独立于抵达能力之外的关键瓶颈。
2. 本文从终止决策角度分析小规模 VLM 的校准失效，揭示以 STOP 为主实例的高代价提交决策存在系统性不可靠性。
3. 本文提出一种可弃权、可主动再观测的可靠终止机制，在提交 STOP 及相关高代价决策前动态补充证据。
4. 本文通过失败分类、校准指标与跨 backbone 实验验证该机制在转化率上的稳定收益，并用轻量提交空间分析说明 STOP 不是唯一的高代价决策点。

## 9. 风险与控制

最大风险是贡献被压缩为“一个带触发条件的 stop verifier”。防御方式是让问题定义和实验指标始终围绕“可靠提交”而不是“终点检测”：

- 主文优先展示 OSR→SR 缺口和校准失效，而不是先讲 pipeline。
- 方法优先讲三态决策、弃权、主动取证，而不是模式切换。
- 实验优先报 conversion、ECE、risk-coverage、false stop / missed stop，而不是只报 SR。
- 相关工作中主动承认 last-mile 和模式切换已有先例，避免过度主张。

第二个风险是 SPL 下降。主动再观测可能增加路径长度，因此必须控制触发频率，并把 SPL 作为约束指标。若 SR 上升但 SPL 大幅下降，AAAI 评审可能认为收益来自额外探索成本。

第三个风险是跨 backbone 成本。若 7B / 8B / 72B 全部评测成本过高，最低配置应保证 4B 与一个中等模型完整对照，再用外部方法结果做跨方法转化缺口分析。

## 10. 下一步执行清单

近期优先级如下：

1. 修改 analyze 脚本，补充 OSR→SR 转化率、false stop、missed stop、min_dist/final_dist、T1–T5 初步分类。
2. 跑 A0 原始 4B 基准，确认当前最佳 ep100 的 OSR/SR 缺口是否稳定。
3. 从 A0 trace 中抽取 STOP 决策置信度，先做 Termination ECE 与风险覆盖曲线。
4. 实现 arrival gate 的 log-only 版本，只记录不干预，评估触发质量。
5. 实现最小 R1：进入近目标证据后允许终止候选与保守提交，观察漏停是否下降。
6. 再加入 T2/T4 验证与三态弃权，形成可投稿方法雏形。
7. 最后决定是否补 ObjectNav / EQA / 跨指令类型作为半个 L3 泛化实验。

## 11. 当前结论

本方案的上升方向不是继续强调“到达感知异构 pipeline”，而是将其转化为“小模型在高代价提交决策中的可靠提交问题”。这一路线更符合 AAAI 对清晰问题定义、可解释机制、充分实验支撑和泛化证据的偏好。

最终论文应让评审记住的不是“我们加了一个终点监测器”，而是：

> 小模型具身智能体的一个关键瓶颈，是它们可以接近目标，却不能可靠决定何时提交 STOP、目标指代、分支选择和终止视点这类高代价决策。本文把这个瓶颈形式化为 OSR→SR 转化缺口，并用校准分析、弃权机制与主动再观测来修复。
