## 2. 已确立的核心事实（后续所有设计的前提）

1. **终止信念与现实脱钩**：置信度对到达零信息量（9B ECE 0.463，全桶到达率 6–13%；跨 backbone 一致）；可见性报告率随距离平坦（半径内 46% vs 5–8m 处 51%）。
2. **选路是选择层问题**：迷路集 640 决策点 48% 走远 ≈ 随机游走；~84% 决策点存在好候选。waypoint 生成路线正式关闭。
3. **不确定性探测不到**：三探针（离散度 AUROC 0.54 / 自报退化 / logprob 待补）预注册闸门全 FAIL；错误是"全票一致的自信错误"。触发式再观测路线（P1）关闭。
4. **信息注入无增益**：P0 几何注入配对 p=0.21。瓶颈不是信息量。
5. **推理路径零 GT 是铁律**：所有以米为单位的推理期阈值必须过血统检查。

## 4. 纪律（历次教训沉淀，不可省略）

- **预注册闸门**：先写死判定标准再跑（AUROC 线、成功线、灰区裁决规则）。
- **配对检验**：ep100 上一切对比用逐集 McNemar，点估计差 2–4pp 不作声明。
- **血统检查**：任何新触发/门控信号，wiring 前查数据源（oracle 泄漏即由此抓出）。
- **单开关 A/B**：一次只开一个机制，归因高于速度。
- **贵决策挡在便宜测试后面**：smoke 挡全量、离线挡在线、保真挡重跑。
- **目录名会撒谎**：模型身份以 trace metadata.llm 为准（见 paper_analysis/verify_paper_numbers.py 头注）。
