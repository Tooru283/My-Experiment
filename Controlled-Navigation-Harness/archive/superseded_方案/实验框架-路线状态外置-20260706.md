# 实验框架：路线状态外置（Route-State Externalization）

> **[已被取代 2026-07-13]** 本版（v1.0 + v1.1 补丁）已整合重写为 [[实验框架-路线状态外置-20260713]]，后者含 Phase 0 最新状态、两轨重组与预算表。本文件保留作演化记录。

## 0. 一句话

小 VLM 的内部信念不可用（校准死、探针死、实例绑错），但**显式维护的路线状态 + 几何证据是活的**（路线一致性初测 AUROC 0.748 vs 探针 0.54；角度/深度/里程计零校准可用）——把整个决策系统的证据源从"模型自报"换成"外置路线状态"，一个中枢喂三个决策面。

## 1. 核心架构：一个状态机，三个决策面

**路线状态机（程序化维护，非 VLM 内省）**：
指令解析为有序子句序列（方向词 + 地标词）→ 逐步用 VLM 的**感知输出**（每视角地标匹配，它唯一可信的用途）推进匹配进度 → 维护：已完成子句、已见地标集、当前期待约束（方向 + 地标）、单调进度。

| 决策面 | 机制 | 证据源 | 对准的失败 |
|---|---|---|---|
| **选路** | 约束驱动候选过滤/重排：期待"左转见 doorway"→ 左侧含 doorway 候选加权 | 路线状态 + 候选 angle_deg（几何） | 48% 随机游走（84% 有好候选选不中） |
| **终止** | 路线一致性门（覆盖×顺序×步数）∧ 类别匹配 ∧ depth veto；终段过桥记忆（carry_forward+深度） | 路线状态 + 深度 + 里程计 | 56 假停（泛类地标实例绑错）+ 5 擦边 |
| **恢复** | 未匹配约束驱动的主动观察（"期待 doorway 而候选无 → 转身找"）+ 位移停滞回溯 | 显式未匹配约束 + 里程计 | 23 耗尽 / 死胡同 |

**红线**：VLM 只作感知（"这个视角里有什么"），永不作信念（"我到了吗/我确定吗"）；一切以米为单位的推理期比较过血统检查；触发条件必须可计算（显式约束/几何），不用不确定性估计（已证不可测）。

## 2. 实验阶段与闸门

### Phase 0 — 离线验证（本周，零 GPU，现有 trace）

| # | 实验 | 产出 | 闸门 |
|---|---|---|---|
| P0.1 | **方向词违反率**：迷路集 640 决策点 × 指令方向词 × 所选候选角度 | 选路面最便宜一层楼的高度 | 违反率>25% → 方向先验必做 |
| P0.2 | **有序路线一致性特征**（顺序匹配+覆盖+步数）+ bootstrap CI。**v1.1 统计修正**：真停正例太少（clean 仅 11）——阈值/特征在 Run1+4B 旧 trace 的正例池（~45 例）上拟合，**最终闸门只在 clean trace 上评一次**（防双重使用） | 停止门的正式信号验证 | AUROC≥0.72 且下界>0.65 → 上线 |
| P0.3 | 选路面离线重放：好候选中"符合当前约束"的比例（约束过滤的理论增益） | 选路先验的天花板 | — |
| P0.4 | **重复提停频率**（N1 前置）：假停/被拦集中，停止请求的空间聚集度（同一 ε 邻域内重复提停次数分布） | N1 黑名单的靶子大小 | 重复率>30% → N1 进 Phase 1 |

### Phase 1 — 单开关 A/B（每个 ep100 vs clean_baseline_v1，配对 McNemar）

| # | 实验 | 预注册成功线 | 预期 |
|---|---|---|---|
| A | depth veto（已 staged） | 6 靶集追回≥4，零误杀 | +2~4 SR |
| B | 路线一致性停止门 | 假停拦截≥60%，真停误杀≤1 | +2~4 SR（续命→OSR） |
| C | 方向/约束候选先验 | 迷路集净增益均值显著>0（脱离随机游走） | +OSR 3~6 |
| D | 回溯（已 staged） | 耗尽集方向为正，SPL 降幅<0.02 | +1~3 |
| E | **N1 负目标记忆**（P0.4 已过闸：重复提停 38%）：停止被拒→该位置记负证据，累计 2 笔进黑名单冷却区（拒停 + 候选降权） | 重复提停下降≥50%，不新增误杀 | +1~3（与 B 协同） |

**依赖修正（v1.1）**：E 的写入事件主要由 B 的路线门拒绝供给——E 不是真正独立的单开关。Phase 1 重组为两轨：
- **终止轨**：A（vs 基线）→ B（vs 基线）→ **B+E（vs B）**——E 的归因对象是 B，不是干净基线；
- **选路轨**：C（vs 基线）→ D（vs 基线），与终止轨在 GPU 上交错排程。

**报告模板统一加两轴（v1.1，借 REALM 指标思想）**：
1. **停止证据充分率**：每次 STOP 提交时记录通过了哪些门（路线覆盖/深度/持续性），报告"证据充分的停止占比"——我们自己的可观测版 OracleGS，也是论文的诊断图；
2. **成本轴**：每臂报告平均步数、VLM 调用数、SPL——路线门拦停会续命 episode，成本不报会被审稿人抓。

每跑完在 [[sr_roadmap_20260706]] 对账表记实测。

### Phase 2 — 合并系统 + 对照（~1 周）

- **Route-State v1**（A+B+C+D 最优组合）ep100 + **交互效应分析**
- **harness-off 9B**（转化率声明的合法对照）
- **4B 跨 backbone**（机制不绑 9B 的证据）
- 达标线：SR ≥22、OSR ≥26（= 收复 oracle 时代水位，但这次是干净的）
- **v1.1 降级底线（预注册）**：若仅终止轨（A/B/E）有效、选路轨不显著——最低可发表结果 = "可观测证据门追回 ≥4 点 + 逐集归因 + C1/C3"，达标线降为 SR ≥20；不因合并数字不好看而回头调单开关配置
- **v1.1 提交前硬闸**：headline 数字须在 **完整 val_unseen（1839 集）** 复验一次（~9 天 GPU 挂后台，或预注册 500 集分层子样）——n=100 是审稿最大软肋，最终数字不能只有它

### Phase 3 — 训练线（backbone 快筛后）

- backbone 快筛（ep20 × 候选小 VLM，看 E1 校准剖面选基座）→ **定基座后**才开训
- 选路打分头：输入 = 路线状态特征 + 候选几何 + VLM 感知输出（Phase 1-C 的特征工程直接复用），oracle 测地标签离线监督
- 闸门：held-out 选中率 ≥55% 才上线；在线 OSR +≥4（配对）
- 预期：OSR 30+，SR 冲 25~30 区间

## 2b. 机制融合判定（2026-07-06，库内机制 → 本框架）

**融合出新（拟纳入）：**

| 新机制 | 融合来源 | 内容 | 论文位置 |
|---|---|---|---|
| **N1 负目标记忆（实例黑名单）** | ConsistNav 非对称证据 × 本框架路线核验 × HiMemVLN 局部记忆 | 路线门每拒绝一次停止，向该空间位置记一笔负证据；≥2 笔进黑名单冷却区（拒停+候选降权）。锚点的对偶：**记"不在哪"比记"在哪"鲁棒**——负判定来自程序化路线核验（可信），正判定来自 VLM 感知（不可信）。VLN-CE 无先例 | 正文，核验面组成部分（P0.4 过闸后） |
| **N2 约束条件化感知预算** | AutoGaze token budgeter × 路线状态 | 按"当前期待约束"分配感知：期待左侧 doorway → 只对左侧候选视角发 VLM 调用、目标区高分辨率。省调用（现每步 8–15 次）+ 把感知预算砸在决策相关区 | 效率章 + 消融，不进核心叙事 |
| **N3 状态转移门控慢-快调度** | DualVLN / FSR-VLN × 状态机 | 路线状态每步更新（程序化、廉价）；完整 VLM 推理仅在状态转移（子句完成/约束违反/停止提议）触发。调用少→幻觉注入面小 | 实现节，系统贡献 |

**直接吸收（补引用）**：CA-Nav 约束分解（=子句 schema，从 value-map 驱动改为三决策面驱动）；Progress-Think 单调进度（状态机内置）；MSNav 目标布局（终点上下文并入子句约束）；HiMemVLN 回环软惩罚（恢复面）。

**只引用不做**：MSGNav VVD（3m 半径下站位精度非约束）；AbstainEQA（弃权思潮定位）；**Dual-Anchoring（related work 专段：同病两方——它诊断状态漂移用训练头锚定，我们诊断信念脱钩用外置状态机，训练式 vs training-free 对照）**；SmartWay occupancy 航点（路线已关）；**REALM（arXiv 2607.03792，REVERIE-CE 实例接地，2026-07 新读）**——三重引用价值：① 其"80% 传统成功从未看见目标"= **SR 通胀的第二机制**，与我们的 oracle 补贴（第一机制）并列进评测卫生章；② 下游互补：它以"上游已停在目标邻域"为前提修姿态对准（短程训练样本 = 倒数第二节点 ±5m 扰动），我们修它的前提——停止决策本身；其 VSP（训练损失，模拟器可见性标签）是我们可观测停止门的训练式同构，引作收敛证据；③ 其结论原文 "make reliable stopping decisions under partial observability... remain open" 可直接引用开场。**竞态记录**：MSGNav（2511）→ ConsistNav（2605）→ REALM（2607），8 个月三篇填充"到达质量"空间、全部止步于下游格子并把停止决策可靠性列为 future work——方向确认 + 倒计时。

**堆料纪律**：每个进正文的机制必须对应一个被测量过的失败类 + 一行消融。正文机制清单封顶 = 状态机 + 三决策面 + N1 + depth veto；N2/N3 进效率与实现节；对不上失败类的进 future work。

## 4. 风险与对冲

| 风险 | 对冲 |
|---|---|
| 指令解析（子句/方向词抽取）本身出错污染全链 | 解析用规则+LLM 混合，Phase 0 抽样人工核对 50 条；解析置信低的子句降权而非硬约束 |
| 约束过滤过强 → 正确但"绕路"的候选被杀 | 软惩罚不硬过滤；保底保留 top-1 无约束候选 |
| n=11 真停正例太少，停止门阈值过拟合 | 阈值在 Run1/4B 旧 trace 上交叉验证；最终报 full val_unseen |
| Phase 1 各开关正交性假设不成立 | Phase 2 专设交互效应分析；合并跑与单开关跑同 seed |
