# 总方案（执行版）：零样本 VLN-CE 中小模型近目标终止的可靠提交

本版基于 2026-06-29 的实测进度撰写，取代此前两份方案草稿。与前几版的区别在于：研究主张已从假设变为有数据支撑的结论，方案据此收窄为一条可在四周内执行、并带明确决策闸口的关键路径。目标会议 AAAI-27（摘要 7/20、全文 7/27），时间是首要约束。

## 1. 现状：已被数据坐实的部分

在同一组 100 集 val_unseen、相同种子与模型下，A0 与全开 decision-effect 的 max_config 给出如下对照：

| 配置 | SR | OSR | OSR→SR 转化率 | SPL |
|---|---:|---:|---:|---:|
| A0（原始 Open-Nav + 4B） | 16 | 25 | 64.0% (16/25) | 0.102 |
| max_config（U1+U2+U3 全开） | 21 | 26 | 80.8% (21/26) | 0.142 |

三点已经成立。第一，转化缺口真实存在，且受控机制把它从 64% 提升到 81%，+5pp 的 SR 完全来自 decision-effect，已排除采样噪声。第二，OSR 几乎不动（25→26），证明收益来自“更可靠地终止”而非“更会导航”——这与论文定位一致，也意味着不应与 P2DNav（4B SR 35、OSR 51）比绝对 SR。第三，激活 stop verifier 后，主失败模式从“走过不停”（walk-through，7→2）迁移为“STOP 被门控过度拒绝”（stop-blocked，0→3）。这一迁移本身就是论文的核心实证动机：问题不在于有没有终止判断，而在于终止判断是否可靠。

## 2. 论文主张与实证主线

主张：在零样本 VLN-CE 中，小规模 VLM 的剩余瓶颈是近目标终止的可靠性，而非抵达能力。实证主线分四步，且每一步都已有或即将有数据：

第一步，量化 OSR→SR 转化缺口，并证明它是独立于巡航能力的瓶颈（A0 vs max_config 已完成；跨方法观测 P2DNav 转化率亦仅 69% 作旁证）。第二步，证明朴素地加入 stop verifier 只会把漏停问题迁移为过度拒绝问题，从而暴露真正矛盾是终止决策的可靠性（失败模式迁移已观测到）。第三步，刻画小 VLM 终止验证器的系统性失准——尤其近距离时目标占满视野导致 `final_target_not_visible`（占全部拒绝的 91.7%），并出现“1.78m 拒绝、3.3m 反而允许”的可见性反转（ep377）；用校准与风险-覆盖指标量化。第四步，提出可弃权、可主动再观测的可靠终止机制修复该失准，并证明收益跨 backbone 一致。

## 3. Novelty 边界（保持诚实）

不主张首次提出或命名 last-mile（MSGNav、SLING、AnyImageNav 已有），也不主张“按阶段切换处理模式”的架构（SLING、SAGE-Nav 已有）。可辩护的创新集中于三点：在指令跟随的零样本 VLN-CE 中首次把 OSR→SR 转化作为中心可测目标并给出终止失败分类；对小 VLM 终止验证器近距离失准的刻画与以弃权/主动再观测为核心的修复（区别于 SAGE-Nav 靠训练得来的可信门控）；以及该机制跨 backbone 的一致性。与 SAGE-Nav 的关键区分：其门控可靠性来自训练，本工作处于零样本设定、对齐信号本身失准，故不在不可信分数上做连续混合，而在证据不足时弃权并主动取证。

本轮明确不做、推迟到后续版本的有两项：跨任务（EQA / ObjectNav）泛化，以及 `commitment decisions`（REFERENT / BRANCH / VIEWPOINT）的大框架。四周内无法交付，且只做 STOP 一类会被判 overclaim；本轮的一般性由跨 backbone 承担。

## 4. 理论基础：可弃权的序贯终止决策

本节的目的是让方法有理论落点，而不是读成 prompt 工程。需要先声明：以下框架均为经典结果，本工作不主张理论创新，而是用它作为机制设计的依据与评测框架。

形式化。在近目标阶段第 t 步，记隐含事件 A_t 表示"智能体已位于目标成功半径内且处于可终止视点"。验证器（V1/V2）给出一个到达信念 b_t ∈ [0,1]（取自其置信度或 verdict 概率）。可选动作有三：COMMIT（执行 STOP，不可逆，结束 episode）、CONTINUE（继续导航）、REOBSERVE（主动再观测，付出代价 c_obs，换取新证据后重判）。终止损失非对称：误停（¬A_t 时 COMMIT）记 c_FS，漏停（A_t 时不停、随后离开半径）记 c_MS，且 STOP 的不可逆性放大了误停代价。

一次性最优规则。暂不考虑 REOBSERVE 时，COMMIT 与 CONTINUE 的期望损失分别为 c_FS·(1−b_t) 与 c_MS·b_t，于是贝叶斯最优规则为：当 b_t > τ 时 COMMIT，其中 τ = c_FS /(c_FS + c_MS)。这说明现行手调的 0.95 阈值本质上隐含假设了某个（很可能不正确的）代价比；正确做法是把工作点从代价比或风险-覆盖曲线上定出，而非手调。

为何必须校准。上式有效的前提是 b_t 已校准，即 P(A_t | b_t = p) = p。一旦验证器失准——你已观测到近距离系统性失准、以及 ep377 的"1.78m 拒绝、3.3m 反而允许"这类非单调失准——对原始 b_t 卡阈值就不再贝叶斯最优。这把 Termination ECE 与可靠性图从"附加分析"提升为"理论必需"：它们正是用来判定 b_t 能否当作可信提交信号、以及是否需要重校准。

为何弃权再观测。当 b_t 落在 COMMIT 与 CONTINUE 期望损失接近的不确定带时，一次额外观测能降低后验不确定性、从而降低期望损失；只要降低量超过 c_obs，REOBSERVE 即具有正的信息价值（value of information）。这就是"弃权并主动取证"的理论依据，对应序贯分析中"继续采样直到似然比越界"（Wald SPRT）与最优停止。换言之，忠实模型是序贯最优停止问题，上面的一次性阈值只是其贪心近似。

评测框架。把"是否已提交"视为覆盖率、把已提交决策中的错误视为风险，终止决策天然落入选择性预测（selective prediction / reject option）的评测框架，风险-覆盖曲线为其标准工具；REOBSERVE/CONTINUE 对应延迟提交，与 learning-to-defer 的"预测或延迟"结构同构。

映射到本工作。T1–T5 是该框架下不同的错误与代价类型：T1（漏停）对应高 c_MS 区，T2（误停）对应高 c_FS 区，T4（视点不满足）对应 b_t 不可信需再观测，T5（漂移）对应 CONTINUE 的额外代价。RC3（近距离不可见）被解释为 b_t 在近距离的系统性失准，因而其 not_visible 不应作硬拒绝，而应触发再观测——这把 RC3 的修复直接落到 VoI/弃权机制上，而非临时补丁。

三点诚实边界（须在论文中写明）。其一，一次性阈值是序贯问题的贪心近似；以序贯框架为忠实模型、阈值规则为可计算近似，不声称求得序贯精确最优。其二，本工作以理论指导机制设计（阈值来自代价比而非手调、再观测发生在不确定带、提交前重校准）并借其评测工具，而非证明新定理，须如实表述为 principled approximation。其三，框架本身经典，创新不在框架，而在设定（零样本 VLN-CE 指令跟随）、对小 VLM 终止信念失准的实证刻画与零样本实例化，与既定 novelty 边界一致。

参考：Chow (1970) 最优识别-拒绝权衡；El-Yaniv & Wiener (2010) 选择性分类与风险-覆盖的基础；Geifman & El-Yaniv (2017, NeurIPS; 2019, ICML, SelectiveNet) 深度网络的选择性分类；Mozannar & Sontag (2020, ICML) learning to defer；Guo et al. (2017) 现代网络的校准；Wald 的 SPRT 与 Howard (1966) 的 value of information。

## 5. 关键未决问题（决定贡献成立与否）

当前残余的 4 个 OSR-only 失败集（ep824/1106/1084/377）全部指向同一根因：**近距离时视觉验证器无法识别目标**。这正是 distinctive 贡献的所在。需要强调：目前 16→21 的增益主要来自相对通用的 U1/U2/U3 全开，本周针对近目标的 M2a/M3 仅修好 ep11 一集；如果论文要立在“校准感知的可靠终止”上，就必须证明针对 RC3 的机制能在通用配置之外继续把转化率往上推。RC3 修不动，则论文只剩通用工程增益，不足以支撑 AAAI。

RC3 的修复应当被框定为弃权/主动再观测机制的实例，而非三个临时补丁。理由是校准分析已表明近距离的 `not_visible` 信号本身不可信（ep377 反转），因此不应作为硬拒绝。对应做法：当目标在近几步内可见、当前因过近而不可见时，不直接拒绝，而是调用累积证据或主动换视角再观测后再决定。三种候选实现（距离衰减软拒绝、arrival_evidence 替代、近距换视角重采）在实验中作为该机制的不同实例对照，并与现行硬拒绝、朴素软衰减一并消融，以证明“可弃权/再观测”优于“硬拒绝”和“无脑放宽”。

## 6. 指标（与理论对象对齐）

为使指标不是零散数字，而是第 4 节理论对象的直接度量，先固定操作性定义，再列指标。

操作性定义。决策点指近目标步，即 `latest_goal_dist ≤ R_near`（取 3.5m，与现行 proactive gate 一致）的步，或 V2/completion gate 实际触发的步；所有终止类指标都在决策点上统计。到达真值 A_t 以 oracle 距离近似，A_t = 1 当且仅当该步 `distance_t ≤ 3m`（成功半径），viewpoint 条件暂以距离近似，论文须说明该近似。到达信念 b_t 取自验证器置信度，候选来源包括 V1 的 `final_target_visible` 置信度、V2 verdict 概率、以及（若可得）selector 的 STOP token logprob；E1 先比较各来源的校准度，选最可校准者作为 b_t 并在全文固定——这一步消除了"信念分数取哪个"的歧义。非对称代价以代价比 ρ = c_FS / c_MS 为超参，论文报告若干 ρ 下的工作点，而非手调单一阈值。

每条指标都对应一个理论对象：

| 指标 | 定义 / 算法 | 对应理论对象 |
|---|---|---|
| OSR→SR 转化率 | SR / OSR | 任务级终止可靠性 |
| Termination ECE / Brier | 决策点上对 b_t 分箱，比较桶内平均置信度与经验 P(A_t)；Brier = 均方(b_t − A_t) | 信念校准 |
| 可靠性图 | 同上分箱画 reliability diagram | 校准可视化 |
| 距离分桶 接受率/可见率/真到达率 | 按距离分桶画 P(STOP allow)、P(final_target_visible)、经验 P(A_t) 三条曲线 | 近距离失准与 ep377 反转的直接证据（论文动机图） |
| Risk-Coverage 曲线 | 扫描阈值 τ：coverage = 提交决策占比，selective risk = 已提交中的误停率；画 risk-vs-coverage | 选择性预测 / reject option |
| 代价加权选择性风险 | 给定 ρ 下取 c_FS·FS + c_MS·MS 最小的工作点风险 | 非对称损失下的贝叶斯工作点 |
| False Stop / Missed Stop Rate | 决策点上误停、漏停各自比例 | 损失两臂；防止转化靠多停换（当前 gate precision 仅 19%） |
| SR / OSR / SPL / nDTW | 标准指标 | 主结果与不退化约束 |

校准类与风险类指标均可在现有 A0 与 max_config 的 trace 上直接计算，无需新跑——这是最便宜、也最能把工作从"调 gate"抬成"科学问题"的一步。

## 7. 实验计划与关键路径

按四周窗口排定，分必做与决策闸口。

必做、且可立即开始（不依赖正在跑的 ep100）：E1 校准与缺口分析，在现有 A0 与 max_config trace 上按第 6 节操作性定义计算。具体步骤：(a) 比较 b_t 各候选来源（V1 conf / V2 verdict 概率 / STOP logprob）的 ECE，固定最可校准者为 b_t；(b) 画距离分桶的接受率/可见率/真到达率三曲线，定位近距离失准区间并量化 ep377 式反转；(c) 画 b_t 的 reliability diagram 与 risk-coverage 曲线；(d) 报 false/missed stop 与 T1–T5 成分；(e) 验证 max_config 相对 A0 的转化增益不是以 false-stop 上升换取的。产出即论文的动机图与校准证据，且全程不需新跑实验。

ep100（M3）跑完后接续：

E2，记录 M3 完整 ep100 的 SR、转化率、false-stop，确认 ep11 类增益是否泛化、是否引入新的误停。这是“最小可靠终止机制”的数据点。

E3（核心），RC3 修复实验，以理论判据评估。先从 100 集 trace 统计 `final_target_visible` 随距离的真实分布以确定不可信区间；再实现"弃权+再观测"机制——再观测的触发以不确定带近似 VoI：当 b_t 落入 [τ_low, τ_high] 且近 k 步内曾可见时，触发换视角/调用累积证据后重判，而非每步触发（以控 SPL）。把现行硬拒绝、朴素软衰减、与弃权+再观测三者放到同一张 risk-coverage 曲线上比较。成功判据不是"多修了几集"，而是：弃权机制的 risk-coverage 曲线在相同覆盖率下选择性风险更低（曲线支配），且近距离桶的 Termination ECE 下降，同时 false-stop 不显著上升。残余 4 集的转化只是该曲线改善的具体体现。

E4，跨 backbone。在 4B 与至少一个中等模型（7B）上各跑 A0 与最佳配置，给出转化增益随规模的曲线，支撑“机制随规模解耦/鲁棒”。

| 命名 | 配置 | 目的 |
|---|---|---|
| A0 | 原始 Open-Nav 4B | 行为锚点（已完成，SR16） |
| Base | A0 + harness logging | 外壳不改行为 |
| Gate | + 现行 stop verifier（=max_config 路径） | 复现失败模式迁移（已完成，SR21） |
| Reobs | + RC3 弃权/再观测机制 | 核心贡献，待 E3 |
| Full | Reobs + T3/T5 处理 | 完整机制 |

E5（源自相关工作的杠杆隔离消融与分析）。近期工作（AwareVLN、EvolveNav、LocalNav）共同指出，导航收益集中在少数高代价决策点，且来自三个杠杆：提交前评估（pre-commit）、稀疏触发（sparse）、近期证据闭环（carry-forward）——但它们均靠训练/特权监督获得。本工作在零样本、以校准为根据的设定下隔离测这三个杠杆，每条对应第 4 节的理论对象：

- sparse vs dense（AwareVLN 表 4：sparse 65.4 > dense 63.8）：只在 arrival_gate 触发的近目标步验证 vs 每步验证；预期 sparse 在转化率与 SPL 上更优，验证门控设计并避免 dense 的误差自强化。
- pre-commit vs post-hoc（EvolveNav：preflection +3.5 远大于记忆 +0.9）：提交前验证/弃权（到达模式）vs 提交后恢复（U3）；预期 pre-commit 更省步、SPL 更好，直接支撑"提交前风险评估"叙事。
- evidence carry-forward vs memoryless（AwareVLN 闭环 reasoning 作任务状态）：用近 k 步累积证据 vs 仅当前步；直接测 RC3/ep377 反转的修法。

两条分析并入 E1（现有 trace 即可）：oracle 终止上界（用 Habitat 真值算"终止时机完美"的转化率上界，给贡献定 headroom 与天花板）；A_t 做精（以 GT waypoint / 可终止视点替代 dist≤3m，提升校准可信度）。

评测协议须显式声明：本工作为无状态、逐 episode 零样本，无跨 episode 记忆或测试时适应。这区别于 EvolveNav 的 frozen model + test-time rule memory，是更干净的设定，应作为方法学优势报告。

诚实注记：AwareVLN 的 stopping-error 节点（消融 −5.4）是其三节点中最小的（subtask −13.1、deviation −10.3）。说明在充分训练系统里终止不是最大杠杆；本工作聚焦终止，是因为它最干净可测、可校准，且零样本小模型的 OSR-SR 缺口大，而非声称终止是最大杠杆——此点须在 discussion 写明。

决策闸口（约两周内）：若 E1 的校准图清晰、E3 能让残余集动起来、E4 的跨 backbone 增益成立，则按收窄版 L2 冲 AAAI-27。若其中任一不成立，改投 AAAI-28 或 IROS/ICRA，用完整时间补跨任务与 commitment 框架。不赌“abstract 先占坑”，因为 7/20 摘要阶段仍需可信初步结果。

## 8. 下一步（ep100 跑完即可执行）

最优先、现在就能并行启动、不等 ep100：实现校准与缺口分析脚本（E1），在已有 A0 与 max_config 的 trace 上算出距离分桶接受率/可见率曲线、Termination ECE、risk-coverage、false/missed stop 与 T1–T5 成分。这套数字决定 AAAI-27 是否值得冲。

ep100（M3）一结束，按顺序：

2. 跑 RC3 的 trace 分布统计，确定近距离 `not_visible` 的可信区间与阈值（E3 前置）。
3. 实现“弃权+再观测”的近目标终止机制并做三实例对照消融（E3）。

5. 到达决策闸口，依 E1/E3/E4 结果决定投 AAAI-27 收窄版还是改期。

## 9. 风险

最大风险是 RC3 修不动，导致贡献退化为通用工程增益；缓解方式是把 E1 校准分析做扎实——即便 RC3 只部分修复，“刻画并部分修正小 VLM 终止失准”本身仍是可写的科学贡献。第二风险是转化增益被误停换取，必须用 false-stop / risk-coverage 兜住。第三风险是时间，四周从当前状态出发做完 E1–E4 非常紧；决策闸口的作用就是在两周内用数据决定冲刺还是改期，避免赶出一篇半成品。第四，跨 backbone 成本若过高，最低保证 4B 与一个中等模型的完整对照，其余用外部方法的已报转化率做旁证。

## 10. 参考与区分对象

基础与区分：MSGNav（last-mile 命名与 VVD，related 正面区分）；SLING / AnyImageNav（image-goal last-mile 与模式切换先例，提示不以切换为创新）；SAGE-Nav（学习式门控，区分对象兼“过早终止未解决”佐证）；Context-Nav（视点感知关系验证，用于 RC3/视点）；Fast-SmartWay（Disambiguation 与 FPBR，主动再观测参照）；AbstainEQA（弃权理论依据，兼后续跨任务候选）；R3（一次性 STOP 验证）；P2DNav / HiMemVLN（外部强基线与跨方法转化缺口旁证）。

近期需正面定位的三篇训练式工作：

- AwareVLN：把进度/偏航/终止三类关键节点的特权监督蒸馏成稀疏触发的闭环 reasoning，证明关键节点稀疏 reasoning 有效，其三节点恰对应本文 commitment decisions。区分：它训练且终止只是其最小节点；本工作零样本、以校准刻画终止失准。
- EvolveNav：ObjectNav 中以 preflection 做 frontier 选择前的风险预判（preflection 增益远大于自进化记忆），与本文“提交前风险评估”叙事契合。区分：它面向探索效率、依赖 RGB-D map 与跨 episode rule memory；本工作面向 VLN-CE 高代价提交点的校准/弃权，无跨 episode 记忆。
- LocalNav：同为 Qwen3.5-4B，但走蒸馏 + 端侧部署路线，其语义决策（含 `done()`）为蒸馏黑箱，且 future work 自列“视觉确认/失败恢复”为开放方向。区分：本工作 training-free 且正面解决终止可靠性；二者互补，可作未来工作（将可靠终止策略蒸馏入模型以去推理开销）。

以及 selective prediction / learning-to-defer / calibration 等主流 ML 文献，用于提升 AAAI 非导航评审的可读性。
