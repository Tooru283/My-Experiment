# U 系列今日解决方案 2026-06-21

## 1. 今日目标

今天不扩大 U 系列方法范围，先解决审查中会影响实验归因的实现问题：

```text
1. decision_audit 必须能反映真实动作级 override。
2. U3 不能在 ranker 不可信时按原始候选顺序恢复。
3. U_SERIES.ENABLED=true 不能在 harness logging 关闭时静默失效。
4. U1 shadow trace 必须标注它基于 raw observation 还是 V4 augmented context。
5. U2 当前 decision-effect 范围必须显式记录，避免把 rescue-only 误读成完整 STOP verifier。
```

今日原则：

```text
只修归因边界和 trace 可信度；
不改变 U0 的无 U 系列 decision-effect 语义；
不在今天把 U2 扩展为完整 STOP gate 替代器；
不引入新的 planner、动作空间或大规模 prompt 改写。
```

## 2. 问题与修复

### 2.1 decision_audit 不可归因

原问题：

```text
action_pre_step 的 decision_audit 把 original/proposed/final 都写成 next_vp。
因此即使 U2/U3 实际改变动作，最终 audit 也无法证明 override。
```

今日修复：

- 新增统一 `record_u_override()` 入口；
- 每步重置 `unit_override_records`；
- U1/U2/U3 的 `unit_override` 都进入同一个列表；
- `decision_audit` 在最终 `env.step` 前汇总动作级 override；
- `decision_audit.extra.unit_overrides` 保留完整单元事件；
- U1 selector context override 标记为 `action_affecting=false`，避免把 prompt context 改写伪装成直接动作 override。

验收标准：

```text
U0: decision_audit.action_override_count=0。
U1: unit_override 中出现 selector_context，但 action_override_count 不因它直接递增。
U2: 阻断 visual STOP rescue 时，decision_audit.original_action=STOP，final_action=实际 movement fallback。
U3: reselect 生效时，decision_audit.original_action=原 fallback candidate，final_action=恢复后的 candidate。
```

### 2.2 U3 fallback reselect 解释性不足

原问题：

```text
observation_order_fallback 也生成 ranked_candidates。
RecoveryPolicy 只判断 ranked_candidates 是否存在，因此 ranker 不可用时仍可能按原始候选顺序重选。
```

今日修复：

- fallback 结果新增 `recovery_rank_trusted`；
- `visual_evidence_ranked` 且存在 ranked candidates 时才为 true；
- `observation_order` fallback 固定为 false；
- `RecoveryPolicy` 只有在 `recovery_rank_trusted=true` 且 strategy 为 `visual_evidence_ranked` 时才允许 reselect；
- 否则返回 `no_trusted_ranked_recovery_candidates`。

验收标准：

```text
ranker 不可用或失败: U3 只记录 would_apply=false，不改动作。
visual evidence ranker 产出可信排序: U3 才允许 alternate_ranked_candidate。
```

### 2.3 U_SERIES 配置静默失效

原问题：

```text
OPENNAV_HARNESS.U_SERIES.ENABLED=true
但 OPENNAV_HARNESS.ENABLED=false 或 ENABLE_HARNESS_LOGGING=false 时，
validate_a1_harness_config() 会提前 return。
```

今日修复：

- 在 `validate_a1_harness_config()` 中先读取 raw `U_SERIES.ENABLED`；
- 如果 U 系列显式开启但 harness logging 没开，直接报错。

验收标准：

```text
U_SERIES.ENABLED=true + ENABLE_HARNESS_LOGGING=false => ValueError。
当前 run_OpenNav.yaml => 仍通过配置校验。
```

### 2.4 U1 shadow 与真实 U1 ablation 不等价

原问题：

```text
当前 run_OpenNav.yaml 中 V4 是 decision-effect。
U0 记录的 U1 shadow 是基于 V4 已增强后的 selector context，
而真实 U1 ablation 要求 V4 decision-effect 关闭。
```

今日修复：

- `phase_aware_context` 增加 `input_context_source`；
- 当 V4 已应用时写 `v4_augmented`；
- 否则写 `raw_observation`；
- 增加 `u1_shadow_matches_ablation_context`，明确 shadow 是否能代表纯 U1 ablation 输入。

验收标准：

```text
当前 V2/V4+U0 配置下: input_context_source=v4_augmented。
U1 单元实验配置下: V4 LOG_ONLY=true，input_context_source=raw_observation。
```

### 2.5 U2 当前作用域需要显式记录

原问题：

```text
U2 decision-effect 当前只约束 selector STOP 的 visual rescue，
还不是完整的 completion STOP / selector STOP gate 替代器。
```

今日修复：

- `stop_verification` 增加 `decision_effect_enabled`；
- `stop_verification` 增加 `decision_scope`；
- 当前 U2 decision-effect 写 `selector_visual_rescue_only`；
- log-only 写 `log_only`。

验收标准：

```text
U0: stop_verification.decision_scope=log_only。
U2: stop_verification.decision_scope=selector_visual_rescue_only。
```

## 5. 剩余风险

今天未解决完整 U2 方法范围：

```text
U2 还没有接管 completion STOP。
U2 还没有作为完整 STOP gate 替代器。
weak-target adjustment 仍主要是日志与局部证据，不是完整 near-goal policy。
```

原因：

```text
这些属于方法扩展，会改变 U2 的实验变量。
今天先修 trace 和归因边界，避免在不可信 audit 上继续跑实验。
```

下一步建议：

```text
先跑 U0 小样本验证 trace 稳定；
再单独开 U2-rescue-off；
之后再设计 U2-relation-aware / U2-weak-target-adjusted 的独立开关。
```
