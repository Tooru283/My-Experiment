# 选择层打分头设计（Phase 3 开题）

> 由 20260720b–e 离线链逼出的唯一活路。任务书已被数据定死到罕见的精确度，本文把它落成可训练的方案。

## 0. 一句话

在**冻结的 9B 表示**之上训一个**轻量打分头**，学"给定指令+每候选视觉证据，哪个候选的米制 regret 最小"，用 6250 个自采样本的 oracle regret 作监督，推理期零 GT。

## 1. 被数据定死的三条约束（先摆事实，再谈架构）

| 事实（离线实测） | 对设计的强制含义 |
|---|---|
| 有效独立训练样本 **~6250**（25 跑去重，冗余 2.6×，全来自同 100 集 val_unseen） | **不能训大模型**（会背下这 100 集）；只能训**低容量头 + 强正则 + 按集分组 CV**；必须留独立测试集（LOSO：留场景/留集） |
| 候选数中位 4、每步 `visual_evidence`/`selector_context` 100% 可得、`selector_raw` 95% | 输入天然是**变长候选集打分**（listwise）；每候选特征齐全 |
| regret **高度集中**：39% 步贡献 89% regret；大错=90°路口步 | 损失必须**按 regret 加权**（大错步权重高），否则头会去优化无关紧要的小差距——这正是 Arm C 命中率指标的坑 |
| 米制 regret 中位 0.47m、LLM 基线 0.99m/步 | 训练目标 = 回归/排序 regret；**验收 = 米制 regret ≤0.6 + 0.5m/集上线闸门**（§一quater 新规） |
| 方向线索"激活问题"是根因（何时用哪条线索，代理对齐噪声大） | 头**必须同时看指令表示与候选视觉证据**，让模型自己学"此步该不该看方向词"——不能外部硬对齐子句 |

**结论先行**：数据量排除了"训一个新 VLM/视频模型"（REALM 那种 18 万样本 LoRA 的路子我们走不了）。可行域 = **冻结 backbone 表示 + 轻量 listwise 打分头**。

## 2. 架构：三个候选，按数据约束排序

| 方案 | 输入 | 参数量 | 6250 样本下风险 | 判断 |
|---|---|---|---|---|
| **A. 隐层探针头（推荐）** | 9B 在 selector prompt 上对每个候选 token 的**隐藏态** + 候选几何(angle/dist/rank) | ~10⁴–10⁵（1–2 层 MLP/注意力池化） | 低（容量小、表示已含语义） | **首选** |
| B. 结构化特征 listwise | `visual_evidence` 解析出的结构化标量(nmatch/visible/…) + 几何 | ~10³ | 最低，但§三.4 已证标量够不着互补性上界 | 作**下界对照**，不作主方案 |
| C. 独立小编码器（重训 SigLIP/文本塔） | 原始 RGB + 指令 | ~10⁷ | **高**（过拟合 100 集） | 排除，除非数据扩到 10⁵ |

**A 的关键赌注**：9B 的隐藏态里**已经**编码了"这个候选是否符合当前指令方向"——只是它的**输出头**（贪心 argmax over prompt）没把这个信息用好（§三.1：比随机强 9 点、比几何强 1 点）。打分头的作用 = **重新读出 backbone 已有但没用好的表示**。这个赌注可离线证伪（见 §4 闸门 G1）。

## 3. 训练配方

**样本单元**：一个决策点 = (指令, 候选集[每候选: 隐藏态 + 几何 + 视觉证据], regret标签[每候选到目标测地距离])。

**标签**：每候选的 oracle 测地 regret（`distance_to_goal` 差分，训练期用 GT 合法）。用**测地不用欧氏**（假说①虽证伪但测地是正解，r=0.869 下差异小、无成本）。

**损失**：listwise，regret 加权。
`L = Σ_step w(step) · softmax_CE(−ŝ, onehot(argmin regret))` + `λ · MSE(ŝ, regret)`
其中 `w(step) = clip(max_regret_in_step, 0.3, 3.0)` —— 大错步主导梯度。排序项保证选对，回归项保证米制校准。

**正则（6250 样本的生命线）**：dropout 0.3、weight decay、早停按 LOSO 验证 regret；头深度 ≤2 层。

**CV / 测试**：GroupKFold **按场景**（不是按集——同场景不同集仍泄漏布局）。11 个 val_unseen 场景 → 留 2 场景做测试，绝不进训练。这是防"背下 100 集"的唯一保险。

## 4. 预注册闸门（跑之前写死，防 Arm C 重演）

| # | 闸门 | 标准 | 不过的处置 |
|---|---|---|---|
| **G1-下界**（✅ 20260720 已跑，结构化标量版） | numpy listwise 头，场景级 GroupKFold-5 | — | **已出：命中 36.8→44.2%，但米制 regret 0.957→0.940（+0.12m/集，远低于 0.5 闸门）**。管道验证通过；确认标量特征触底。`paper_analysis/scoring_head/g1_lowerbound.py` |
| G1 表示有效性（**下一步 GPU**） | 用 9B 隐藏态做**线性探针**预测 regret 排序 | 折外 regret ≤0.85m（优于 LLM 0.99 且优于下界 0.94）且 AUROC(选对)>0.60 | 不过 → 表示里没有可读出的信息 → 方案 A 死，退 C 或换 backbone。**1 天可出** |
| G2 米制效应 | 打分头折外 regret | ≤0.6m/步 **且** 期望 SR 效应 ≥0.5m/集（§一quater 闸门） | 不过不上线 |
| G3 在线兑现 | ep100 配对 McNemar | SR/SPL 方向为正、regret 实测下降 | 不过 → 回到离线找因果链断点（realized regret 复用 20260720b 脚本） |

**G1 是这次的"闸门前移"**：Arm C 的教训是"线性先验离线好看、上线净负"，根因没先验证表示可读性。这次 G1 直接测 backbone 表示的 regret 可分性——比线性先验更接近打分头真实上限，且纯离线。

## 5. 数据管道（复用现成，不新建）

- 标签：`N. 离线复算方法`（current_task §一ter）已给出候选世界坐标重建（θ=−head−angle，误差 0.000m）+ 测地距离，脚本即插即用。
- 隐藏态提取：需在 collect 跑里加一个 hook 记 `selector` 前向的候选 token 隐藏态（类比 p1_design §9.2 的 prompt 日志钩子，**加一个 tensor dump**）——这是唯一需要的新代码，一次 ep100 collect（~12h）产出全部隐藏态。
- 6250 独立样本 + 每次跑增产；先用现有 25 跑的结构化特征跑 G1 的**下界版**（方案 B 特征），确认管道，再上隐藏态版。

## 6. 里程碑与止损

1. ~~**G1 下界（纯离线）**~~ ✅ **20260720 完成**：结构化标量 listwise 头，场景级 GroupKFold-5，
   命中 36.8→44.2% 但米制 regret 仅 0.957→0.940（+0.12m/集）。**管道通、标量触底、第三次确认"命中率≠米制"**。
   隐藏态版必须跨过的地板 = 0.12m/集（跨不过 5× 到 ~0.5 就不值得训）。
2. **隐藏态 collect + G1 正式（下周）**：一次 ep100 记隐藏态 → 线性探针 → **生死闸门**。
3. G1 过 → 训打分头 → G2 → G3 在线。G1 不过 → backbone 快筛（换基座重测 G1）或整条训练线止损、回退到"分析论文 + 诚实基线"的最小可发表版。

**止损纪律**：G1 一天出结果。不过就不投第二天。这是把"贵决策挡在便宜测试后面"用到训练线——过去两周这条规则每次都对。
