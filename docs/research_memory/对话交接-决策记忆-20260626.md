# 对话交接 — 近目标终止方案的决策记忆

> 这是 2026-06-26 一次策略对话的浓缩交接。另一个对话从这里接续即可。
> 完整方案见同目录 `近目标终止-单问题创新方案-20260626.md`(含附录 A 的追赶路线)。

## 1. 项目现状(出发点)

- 项目：Open-Nav 修改版的 Controlled Navigation Harness，零样本 VLN-CE。
- 主跑配置：Qwen3.5-4B(文本模型) + SigLIP + RAM + SpatialBot，R2R-CE val-unseen，ep100。
- 当前性能：**SR 18-19% / OSR 27-29%**(最佳 ep100)。瓶颈是性能提升不高、创新点显得碎。
- 已有设计：V 系列(视觉证据 V1-V4 + fallback)、U 系列(U1 phase-aware / U2 stop verifier / U3 recovery)，多数有 trace、部分 log-only。

## 2. 核心战略结论(本次对话确立)

**不要再加并列模块。把整篇论文压到一个问题上做深：小 VLM 能走到目标附近却停不住(OSR→SR 转化失败 / 近目标终止 / Last-Mile)。**

- 这是最大性能杠杆(每 100 个有 ~10 个"到过没停住")。
- 文献已命名(MSGNav 的 Last-Mile Problem)，但没人占这个切口攻。
- U2(Stop Verifier)升级为论文核心；U1/U3 降为支撑层。

围绕这一个问题分 4 个切面(都属同一问题)：
- A 问题形式化 + near-goal 失败 taxonomy(借 MSGNav 命名 + 自有 analyze 脚本)
- B 视点感知终止验证(借 MSGNav VVD + Context-Nav viewpoint-aware relation)
- C 不确定性可弃权终止——真正新意，for small models(借 Fast-SmartWay Disambiguation +4.5SR + AbstainEQA)
- D 预测-验证停前确认(借 Fast-SmartWay FPBR +3.5SR)

## 3. 几个被否决/修正的方向(避免另一个对话走回头路)

- ❌ **"记忆对小模型没用"当创新点**：现有数据证不了(HiMemVLN 记忆消融在 72B 上是 +11%；且 P2DNav 的 SDM 记忆在 4B 上 +13)。能站住的弱版本是"**瓶颈随规模迁移**"，且仍需自己在 4B 上跑 memory on/off 才能证。
- ❌ **把代码架构往 HiMemVLN 贴**：会毁归因、性能预期错(72B→30 主因是规模)、工程亏。HiMemVLN 只作外部强基线引用。
- ✅ **评测口径已与 HiMemVLN / P2DNav 对齐**：都是 R2R-CE val-unseen / 100-ep / 3m / Open-Nav 框架，可直接并排比。唯一待自查：自己的 100 episode 是否与 Open-Nav 标准那固定 100 个同一批。

## 4. P2DNav 的冲击(关键新信息)

P2DNav(arXiv:2605.19634, Qwen3-VL，同口径)：**4B SR 35 / OSR 51**，32B SR 50 / OSR 65。代码"will be released"未放出。
- 推翻"4B 上限 24-27"——天花板是 **pipeline**，不是模型规模。
- 最大单项杠杆 SDM 对话记忆 +13(32B 消融)；RRM 执行前弃权 +8。
- **冲击**：RRM 部分抢先了切面 C/D 的"执行前弃权"。但 P2DNav 转化率也只有 69%、无专用终止验证器——**近目标终止这个坑它没填**，差异化空间还在。
- 与 RRM 的区分(写进 related work)：RRM 问"这步能不能踏出去"(局部可走性，提 OSR)；本工作问"是不是到了该停"(目标满足性，提 OSR→SR 转化)。互补非竞争。

## 5. 已选定路线

**路线 B：保留 Open-Nav 链路，借机制追，论文定位"受控诊断 harness + 近目标终止决策"。**

诚实预期：大概率从 18-19 拉到 mid-20s，**追平 P2DNav-4B=35 概率不高**(不改 pipeline，OSR 上游差距难补平)。论文不靠打赢 P2DNav，靠三点：干净归因诊断 + 终止转化杠杆 + 跨 backbone 一致性。

## 6. 导航 pipeline 优化(拉 OSR，最新讨论)

OSR 差 22 点是最大杠杆。两个最大杠杆**代码已造好、停在 log-only/关闭**：
- Tier 1：① 激活 **V4 多模态 selector**(让 4B 真正看图，打通文本观测瓶颈，对应 P2DNav 高 OSR 主因)；② **V3 转 decision-effect 做回环抑制**(重访检测+软惩罚，借 HiMemVLN Localer，关掉 OSR -8%)。
- Tier 2：③ 全局方向锚定 FinalTarget/PrimaryDir/CameFrom(借 HiMemVLN Globaler，-4%)；④ 候选 grounding 前移+top-k(OpenFrontier)；⑤ 方向优先解耦(P2D)。
- 提醒：把 OSR 优化到"够用"即可，主力仍押终止决策，别滚成和 P2DNav 拼 OSR 的全系统重写。

## 7. 立即行动清单(M0→M5)

```text
M0  补 A0(4B 裸跑原始 Open-Nav，无 decision-effect) + OSR→SR 转化率/taxonomy 进 analyze 脚本   ← 地基，至今未跑
M1  B1 SDM 式对话记忆(适配文本LLM：近端保留结构化视觉证据 + 远端只留文本)                        ← 最大杠杆，先做
    同期可启 V3 回环抑制 + Globaler 锚定(便宜防漂移)
M2  S1 current-view auto-stop(已设计，先 log-only ep20 → decision-effect ep100)
M3  B2 方向优先解耦 + direction/target 两层 failure 标签；按需激活 V4 多模态 selector
M4  S2/S3/S4 终止验证全套，明确与 RRM 的"目标满足性 vs 局部可走性"区分
M5  跨 backbone {A0, full} × {4B,7B,8B}，产出"终止机制 ΔSR vs 规模"核心图
```
